# AEOlab — ChatGPT 보완 전략 및 개발 계획

> 작성일: 2026년 5월 13일  
> 목적: 개발 마무리 단계 UX 재설계 방향 + 이탈 방지 전략

---

## 1. 문제 인식

### 1.1 현재 상황

소상공인은 ChatGPT를 신뢰한다. 이유는 세 가지다.

- 지도 + 위치 시각화로 직관적
- 상황별 카테고리 분류로 결정이 쉬움 (상견례 / 가성비 / 고기 등)
- 각 가게마다 "이 상황에 맞는 이유" 한 줄 설명
- 후속 질문 옵션 제시로 대화가 이어짐

AEOlab이 점수·그래프·순위를 보여주는 구조라면, 사장님 입장에서는 "ChatGPT에서 직접 보면 되는 것"처럼 느껴진다. 비교 대상이 ChatGPT가 되는 순간 진다.

### 1.2 핵심 통찰

ChatGPT는 **소비자 도구**다. 사장님이 쓸 수 없는 이유가 있다.

- 내 가게가 저 화면에 나오는지 알 수 없음
- 왜 저 가게들이 나오고 나는 없는지 모름
- 지난달과 이번달 변화를 추적할 수 없음
- 출처(블로그 등)가 무엇인지 알 수 없음

AEOlab은 ChatGPT와 경쟁하는 것이 아니라, **사장님 시점의 레이어를 얹는 도구**다.

## 2. ChatGPT 분석 — 상남동 가족모임 한식당 사례

### ChatGPT가 하는 것

| 항목 | 내용 |
|------|------|
| 지도 시각화 | 지역 내 가게 위치 + 평점 핀 표시 |
| 상황 해석 | "가족모임 = 룸 유무, 주차, 어른 만족도, 조용한 분위기" |
| 카테고리 분류 | 상견례·고급 / 가성비 / 건강식 / 고기 |
| 이유 설명 | 각 가게별 한 줄 추천 이유 |
| 출처 표시 | "begin1004 님의 블로그" |
| 후속 질문 | 룸 10명 이상 / 주차 편한 곳 / 1인 2~3만원대 등 |

### ChatGPT가 못 하는 것 — AEOlab의 기회

| ChatGPT의 한계 | AEOlab의 기회 |
|---------------|--------------|
| 내 가게가 나오는지 확인 불가 | 내 가게 노출 여부 즉시 확인 |
| 왜 나오는지 설명 없음 | 출처 추적 + 노출 이유 분석 |
| 시간별 변화 추적 불가 | 월별 히스토리 자동 저장 |
| 개선 방법 제시 없음 | 구체적 개선 가이드 제공 |
| 사장님 시점 없음 | 사장님 전용 대시보드 |

## 3. UX 재설계 전략

### 핵심 원칙

> ChatGPT 화면을 모방하는 것이 아니라,  
> 사용자가 이미 신뢰하는 그 형태 위에  
> **사장님만 볼 수 있는 레이어**를 얹는다.

### 3.1 무료 체험 단계

**목적**: 충격이 아니라 현황을 그대로 보여주는 것

**화면 구조**:

```
[가게명 또는 업종 + 지역 입력]
         ↓
ChatGPT 실제 답변 그대로 표시
 - 지도
 - 카테고리별 가게 목록
 - 각 가게 추천 이유
         ↓
내 가게 위치 표시 (있으면 하이라이트, 없으면 "미노출")
         ↓
[더 자세히 보기 → 유료 전환]
```

**설계 원칙**:
- 연출 없음
- 설명 없음
- 강조 없음
- 사장님이 스스로 읽고 스스로 판단

없으면 사장님이 스스로 봄 → "내 가게가 없네" → 자연스러운 유료 전환 욕구

### 3.2 유료 구독 단계 — ChatGPT 위에 레이어 추가

**레이어 1: 내 가게 카드**

ChatGPT 결과 화면 안에서 내 가게가 어느 카테고리에 들어가야 하는지, 현재 들어가 있는지 없는지를 병렬로 보여준다.

```
[ChatGPT 실제 결과]          [내 가게 현황]
상견례·고급 카테고리           이 카테고리 진입 조건:
 - 경복궁 창원점 ✓             ✓ 룸 예약 정보 있음
 - Sugeumjae ✓                ✗ "상견례" 키워드 블로그 없음
                               ✗ 출처 블로그 0개
```

**레이어 2: 출처 추적**

ChatGPT가 가게를 알게 된 근거(블로그, 리뷰, 언론 등)를 분석한다.

- 경쟁 가게의 출처 개수 및 종류
- 내 가게의 출처 현황
- 부족한 출처 유형 → 개선 방향 제시

**레이어 3: 히스토리**

| 시점 | 노출 여부 | 카테고리 | 출처 수 |
|------|----------|---------|--------|
| 3월 | 미노출 | - | 0 |
| 4월 | 미노출 | - | 1 |
| 5월 | 노출 | 가성비 | 3 |

ChatGPT는 이 변화를 절대 보여주지 못한다.

## 4. 개발 순서 — 기능 추가가 아닌 화면 재배열

현재 개발 마무리 단계 기준으로, 추가 개발보다 구조 재배열이 우선이다.

### 4.1 즉시 적용 (개발 마무리 전)

- [ ] 무료 체험 Hero 영역을 ChatGPT 형태로 재구성
  - 점수 숫자 제거 또는 후순위 이동
  - 실제 AI 답변 텍스트를 전면에 배치
  - 내 가게 미노출 시 조용하게 표시 (강조 없이)

- [ ] 대시보드 메인 카드 구조 변경
  - 기존: 점수 → 순위 → 그래프
  - 변경: AI 실제 답변 → 내 가게 위치 → 점수 (보조)

### 4.2 Phase 1 MVP에 포함

- [ ] 출처 분석 기능
  - ChatGPT가 가게를 인용한 근거 블로그/리뷰 추적
  - 내 가게 출처 현황 표시

- [ ] 카테고리 매핑
  - ChatGPT가 쓰는 분류 기준으로 내 가게 위치 표시
  - "이 카테고리에 들어가려면 무엇이 필요한가" 체크리스트

### 4.3 Phase 2 v1.0에 포함

- [ ] 히스토리 자동 저장 및 시각화
- [ ] 월별 Before/After 카드 자동 생성
- [ ] 후속 질문 시뮬레이터 (사장님이 직접 질문 입력 → 결과 확인)

## 5. 이탈 방지 설계

### 이탈이 발생하는 시점과 대응

| 이탈 시점 | 원인 | 대응 |
|----------|------|------|
| 무료 체험 후 | "ChatGPT에서 직접 보면 되잖아" | ChatGPT가 못 보여주는 것을 무료 체험 마지막에 1개 보여줌 |
| 유료 전환 후 첫 주 | "점수가 뭘 의미하는지 모르겠음" | ChatGPT 화면과 나란히 보여주는 구조로 해소 |
| 1개월 후 | "달라진 게 없음" | 히스토리 + 출처 변화 + 개선 과제 제시 |
| 3개월 후 | "익숙해져서 안 봄" | Before/After 카드 카카오톡 발송 |

### 주간 알림 설계 원칙

"이번 주 변화 없음" 알림은 이탈 원인이 된다. 반드시 아래 중 하나를 포함한다.

- ChatGPT에서 내 가게가 언급된 실제 텍스트
- 출처 블로그가 새로 인용됨
- 경쟁 가게 변화 감지
- 개선 과제 중 완료 항목 확인
- 다음 개선 과제 제시

## 6. 포지셔닝 정리

```
ChatGPT         →  소비자가 가게를 찾는 도구
AEOlab          →  사장님이 그 화면에서 자기 위치를 파악하고
                   개선하는 도구
```

AEOlab은 ChatGPT를 대체하지 않는다.  
AEOlab은 ChatGPT 결과를 **사장님 시점으로 해석하는 도구**다.

이 포지셔닝이 명확하면 "ChatGPT에서 직접 보면 되잖아"라는 반응이 나오지 않는다.

---

## 7. Phase 0 인터뷰 활용

위 전략을 검증하기 위한 인터뷰 수정 포인트:

1. 사장님 앞에서 ChatGPT로 업종+지역 검색 → 결과 함께 봄
2. "이 화면에서 사장님 가게가 어디 있는지 아세요?" 질문
3. AEOlab 무료 체험 화면 보여줌 → 동일한 결과 + 사장님 가게 위치 표시
4. "이 두 화면의 차이가 뭔지 아시겠어요?" 질문
5. 지불 의향 확인

판정 기준: "아, ChatGPT에서는 이걸 모르는데 여기선 알 수 있구나"라는 반응이 나오면 포지셔닝 성공.

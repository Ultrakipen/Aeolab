# 대시보드 UX 재설계 기준 v1.0

> 작성일: 2026-06-09 | 근거: 사용자(소상공인) 관점 재검토

---

## 핵심 원칙 2가지

### 원칙 1 — 보여준다, 가르치지 않는다
- 설명 텍스트 없이 상태를 **즉시 인지**할 수 있어야 함
- 사용자가 읽고 이해해야 하는 것 → 제거 대상
- 색상·아이콘·숫자로 **보는 즉시** 상황이 파악돼야 함

### 원칙 2 — 사장님 언어만 사용
- **허용**: 네이버, ChatGPT, Google, Gemini, 경쟁사, 키워드, 순위
- **금지**: AI탭, AI브리핑, 채널, 키워드 커버리지, 듀얼트랙, Track1/2
- 기술 분류(AI탭 vs AI브리핑 구분)는 **상세 섹션 내부**에서만 허용

## 사용자 프로파일

| 항목 | 내용 |
|------|------|
| 대상 | 소상공인 (식당·카페·스튜디오 등) |
| 기술 이해도 | 낮음 — 스마트폰 앱 수준 |

## HeroCard 상태 표시 기준

### 첫 화면에 노출할 상태: 3가지만

| 표시 항목 | 사용자가 이해하는 의미 | 내부 매핑 |
|----------|---------------------|---------|
| **네이버** | 네이버 검색에서 내 가게가 보이나? | 일반검색 + AI탭 + AI브리핑 통합 |
| **ChatGPT·Gemini** | AI 채팅에서 내 가게가 언급되나? | chatgpt_result + gemini_result |
| **경쟁사** | 주변 경쟁 가게보다 앞서 있나? | myRankInList |

### 표시 방식

```
  네이버     ⚠  잘 안 보임   →  (클릭: 네이버 상세 섹션으로)
  ChatGPT   –  측정 전      →  (클릭: 글로벌 AI 섹션으로)
  경쟁사    🥇  4곳 중 1위   →  (클릭: 경쟁사 섹션으로)
```

- 텍스트는 **상태 1줄**만 (이유 설명 없음)
- 클릭하면 해당 상세 섹션으로 스크롤

### 상세 채널 분류(AI탭/AI브리핑) 노출 위치
- **네이버 섹션 내부** (DashboardInsightZone)에서만
- HeroCard, ScanResultNavBar에서는 노출 금지

## 페이지 구조 기준

```
[사업장명 + 스캔 버튼]
───────────────────────────────
[HeroCard]
  - 결론 텍스트 (AI 검색 노출 미흡/개선 중/양호)
  - 플랫폼 상태 3줄 (네이버/ChatGPT/경쟁사)
  - 오늘 할 1가지 CTA
───────────────────────────────
[오늘 할 일] ← 행동이 두 번째
───────────────────────────────
▼ 네이버 상세  (접힘)
▼ 글로벌 AI   (접힘)
▼ 상세 분석   (접힘)
```

## 작업 기준 체크리스트

모든 UI 수정 전 아래 질문에 답할 수 있어야 함:

- [ ] 이 텍스트를 읽지 않아도 색상·아이콘으로 상태 파악 가능한가?
- [ ] 사장님이 이 단어를 설명 없이 이해할 수 있는가?
- [ ] 사용자가 화면에서 배워야 하는 것이 있는가? (있으면 제거)
- [ ] 첫 화면에서 "뭘 해야 하는지" 1가지가 명확하게 보이는가?

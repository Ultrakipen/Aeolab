## §3. 점검 기준 7축

각 페이지를 아래 7개 축으로 채점 (0-10점):

| 축 | 기준 | 소상공인 관점 |
|----|------|------------|
| **A. 네이버 우선** | 네이버 관련 정보가 상단에 위치하고 행동 가능한가? | 소상공인이 가장 민감한 부분 |
| **B. 정보 정확성** | 노출기간·업종 구분·면책문구가 공식 자료와 일치하는가? | 잘못된 기대 방지 |
| **C. PC/모바일 레이아웃** | 가로 폭·텍스트 크기(min text-sm)·스크롤 구조가 적절한가? | 현장 사용 환경 |
| **D. 이해 용이성** | 원인/근거 설명 포함, 전문용어 없이 이해 가능한가? | IT 비전문가 사용 |
| **E. 실측 데이터** | 더미/임의 수치 없이 실측 기반인가? | 허위 정보 방지 |
| **F. 행동 유도** | 이 화면을 보면 무엇을 해야 하는지 명확한가? | 서비스 가치 전달 |
| **G. 중복 없음** | 같은 내용이 불필요하게 반복되지 않는가? | 정보 과부하 방지 |

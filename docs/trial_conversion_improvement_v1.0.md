## §0. 핵심 진단: 현재 무료 체험의 구조적 문제

### 0.1 약속 vs 실제 전달의 괴리

무료 체험 진입 문구: **"지금 내 가게, AI 검색에서 찾히나요?"**

| 소상공인의 기대 | 현재 실제 전달 | 괴리 |
|--------------|--------------|------|
| "AI에서 내 가게가 나오는지 알고 싶다" | 네이버 AI 브리핑 실측 → **잠김** | 핵심 질문 미답변 |
| "ChatGPT에서 내 가게를 아는지 알고 싶다" | ChatGPT 5회 실행하지만 결과 **미표시** | 비용 쓰고 숨김 |
| "경쟁사와 내가 얼마나 차이 나는지" | 블로그 API 수치 (오차 위험) | 신뢰도 의문 |
| "지금 뭘 해야 하나" | 복사 문구 3개 (TodayOneAction) | ✅ 유일하게 잘 됨 |

**결론**: 헤드라인 약속(AI 노출 진단)과 실제 무료 전달(SmartPlace 체크 + 블로그 수치)의 격차가 크다. 소상공인이 이 격차를 인지하면 "낚였다"는 느낌을 받고 이탈한다.

### 0.2 소상공인의 실제 결정 구조

소상공인은 디지털 마케팅 도구에 대해 세 가지 장벽을 가진다:

```
1. 신뢰 장벽: "이 데이터가 진짜 내 가게 얘기인가?"
2. 효과 장벽: "이걸 하면 정말 손님이 늘어나나?"
3. 시간 장벽: "이걸 배우고 실행할 시간이 없다"
```

현재 TodayOneAction의 복사 문구는 시간 장벽을 해결하지만, 신뢰 장벽과 효과 장벽을 해결하지 못한다.

### 0.3 전환 이탈 지점 (모바일 기준)

```
[결과 상단] 가게명 카드 + 상태 3개 → ★ 첫인상 결정 지점 (y=0~200)
[y=350]   측정 근거 + 경쟁사 목록 → 스크롤 시작
[y=750]   경쟁사 5곳 + 순위 정보 → 이탈 위험 1 (수치의 의미 불분명)
[y=1200]  AI 브리핑 잠김 박스 → 이탈 위험 2 (핵심 정보 막힘)
[y=1800]  블로그 격차 수치 → 이탈 위험 3 (신뢰도 의문)
[y=2300]  TodayOneAction → 여기까지 도달한 사용자만 가치 경험
[y=3800]  이메일 저장 입력창 → 전환 CTA 최하단 (도달률 낮음)
```

**핵심 문제**: 가장 가치 있는 콘텐츠(TodayOneAction)가 3화면 스크롤 뒤에 위치. 대부분의 소상공인은 이 지점에 도달하기 전에 이탈.

## §1. 소상공인 심리 모델 — 구독 결정의 Aha Moment

소상공인이 유료 구독을 결정하는 순간은 두 가지 감정 중 하나다:

### 감정 A: 경쟁 위기감 (가장 강력한 전환 트리거)
> "경쟁 가게는 AI에서 나오는데, 나는 안 나온다"

- 발동 조건: 경쟁사가 AI에 노출되고 내가 안 된다는 사실을 **구체적 수치로** 확인
- 현재 충족 여부: ❌ 부분 충족 (블로그 수치만, AI 노출 여부 미표시)

### 감정 B: 개선 가능성 확신 (전환 보조 트리거)
> "이걸 하면 2~4주 후에 실제로 달라진다는 걸 믿을 수 있다"

- 발동 조건: 사례 증거 or "14일 후 변화 측정" 약속의 신뢰성
- 현재 충족 여부: ⚠️ 문구는 있으나 강조 부족

### 감정 C: 귀찮음 해소 (전환 보조)
> "혼자 매주 체크하는 건 불가능, 자동으로 해줬으면"

- 발동 조건: 반복 모니터링의 필요성 인식
- 현재 충족 여부: ✅ Sticky CTA에서 언급되나 연결이 약함

## §2. 개선 방향 5가지

### 방향 A — 핵심 질문에 즉시 답하기 (최우선)

**문제**: ChatGPT 5회 결과를 이미 실행하는데 숨김. 이걸 보여주는 것만으로 핵심 약속 이행 가능.

**개선안**: 결과 상단에 ChatGPT 5회 샘플 결과 시각화

```
╔═══════════════════════════════════════╗
║  ChatGPT에 "서울 강남 커피전문" 검색 시  ║
║                                       ║
║  내 가게:  ○ ○ ○ ○ ○  0/5회 언급     ║
║  경쟁사:  ● ● ● ○ ○  3/5회 언급     ║
║                                       ║
║  AI가 경쟁 가게는 알지만              ║
║  내 가게는 아직 모릅니다              ║
╚═══════════════════════════════════════╝
```

- **추가 비용**: 0원 (ChatGPT 5회 이미 실행 중)
- **구현 규모**: 소 (백엔드 결과 필드 확인 → 프론트 카드 추가)
- **전환 기여**: 경쟁 위기감(감정 A) 직접 발동

### 방향 B — 결과 상단 정보 밀도 개선 (고우선)

**문제**: 결과 상단에 상태 아이콘 3개가 있지만 의미 전달이 약함. "키워드 보강 필요", "아직 미노출" 이 소상공인에게 어떤 손실인지 즉시 와닿지 않음.

**개선안**: 상태 카드에 "경쟁사 대비 손실 추정" 한 줄 추가

```
[현재]
! 네이버 검색
  키워드 보강 필요

[개선]
! 네이버 검색
  키워드 보강 필요
  → 경쟁 가게 대비 월 방문자 약 30~50명 적을 수 있음 (추정)
```

- **주의**: 추정값이므로 반드시 "(추정)" 배지 + 근거 1줄 필수 (CLAUDE.md 실측 원칙)
- **구현 규모**: 소
- **전환 기여**: 손실의 구체화 → 행동 동기 강화

### 방향 C — TodayOneAction을 결과 상단으로 끌어올리기 (고우선)

**문제**: TodayOneAction이 y=2300에 위치. 소상공인 대부분이 도달 전 이탈.

**개선안 C-1**: 결과 상단 영웅 카드 내에 "1번 액션 미리보기" 삽입

```
[결과 상단 카드]
AI 검색 노출 시작 전
...상태 3개...

▼ 지금 바로 할 수 있는 1가지
  소개글에 '스페셜티 커피' 추가 → 2~4주 내 순위 변화
  [복사 문구 보기 ↓]  (→ #today-action 앵커)
```

**개선안 C-2**: 스크롤 없이 첫 화면에서 이메일 입력 가능하도록 상단 이메일 CTA 추가

```
📧 개선 문구를 이메일로 받아두세요 (무료)
[이메일 입력]  [저장하기]
14일 후 변화 측정 결과도 함께 보내드립니다
```

- **구현 규모**: 중 (ResultSummaryHero 컴포넌트 수정)
- **전환 기여**: 이메일 확보 → 14일 후 재방문 → 2차 전환 기회

### 방향 D — 14일 후 재스캔을 핵심 가치로 전면화 (중우선)

**문제**: "14일 후 무료 재측정" 약속이 TodayOneAction 이메일 입력 박스에만 있어 노출 부족. 이것이 사실상 가장 강력한 무료 훅인데 숨겨져 있음.

**개선안**: 결과 상단 Sticky CTA 문구 개편

```
[현재]
7일 후 AI가 내 가게를 인식했는지 자동으로 확인해 드립니다
→ [회원가입하기]

[개선 방향]
소개글 수정 후 → 14일 뒤 순위 변화 무료 확인
이메일만 남겨두면 직접 측정해서 알려드립니다
→ [무료로 변화 받아보기]  → [구독으로 매주 자동 추적]
```

- **핵심 전환 로직**: 무료(이메일 저장 → 14일 후 재스캔) → 유료(매주 자동 추적)의 2단계 깔때기
- **구현 규모**: 중 (Sticky CTA 로직 분기, APScheduler 14일 재스캔 잡 추가)

### 방향 E — 블로그 수치 신뢰도 개선 (저우선)

**문제**: 블로그 언급 수치가 일반명사 가게명 등에서 크게 왜곡될 수 있음. 소상공인이 "86건 격차"를 보고 잘못된 불안을 가질 수 있음.

**개선안**: 신뢰도 구간 표시 + 직접 확인 유도

```
[현재]
내 가게 0건 vs 파티세리 후르츠 86건

[개선]
내 가게 0건 vs 파티세리 후르츠 86건
⚠ 가게명이 일반 명사를 포함할 경우 ±30건 오차 발생 가능
→ 정확한 블로그 언급은 [직접 확인하기] (네이버 블로그 검색 새탭)
```

## §3. 전환 퍼널 재설계 (목표 구조)

### 현재 퍼널 (문제)
```
결과 진입
  → [y=0] 가게명 + 상태 3개 (의미 불분명)
  → [y=750] 경쟁사 목록 (이탈 1)
  → [y=1200] AI 브리핑 잠김 (이탈 2, 신뢰 손상)
  → [y=2300] TodayOneAction (여기까지 도달한 소수)
  → [y=3800] 이메일 저장 (극소수)
  → Sticky CTA: 구독 유도
```

### 목표 퍼널 (개선 후)
```
결과 진입
  → [y=0] 가게명 카드 + ChatGPT 5회 결과 ★ (즉시 Aha)
  → [y=200] 이메일 입력 (무료 재측정 약속) ← 상단 노출
  → [y=400] 경쟁사 대비 손실 추정 + 액션 1개 미리보기
  → [y=800] TodayOneAction (앞으로 당김) ← 복사 문구
  → [y=1500] 더 많은 근거 (블로그/경쟁사/스마트플레이스)
  → [y=2000] LockedScoreCard (구독 유도)
  → Sticky CTA: 이메일(무료) 또는 구독(유료) 선택
```

## §5. 가장 중요한 단일 개선: P0

ChatGPT 5회 결과를 지금 당장 표시하는 것이 가장 임팩트가 크다.

**이유**:
1. 추가 비용 0원 — 이미 실행 중
2. 핵심 약속("AI 검색에서 찾히나요?")을 이행함
3. 내가 0/5, 경쟁사 3/5이면 경쟁 위기감(감정 A)이 즉시 발동
4. 이 하나의 수치가 "나는 지금 손해보고 있다"는 인식을 만들고 행동 동기를 형성

**구현 조건 확인 필요**:
- `trial_scans` 테이블에 `chatgpt_result` JSON이 저장되는지 확인
- `chatgpt_result.mentioned_count` / `chatgpt_result.sample_size` 필드 존재 여부
- 프론트 `TrialResultStep`에서 이 필드를 받아 시각화

## §6. 구독 가치 제안 재정의

현재 구독 CTA: "회원가입하기 (1분)"
→ 추상적. 가입 후 뭘 얻는지 불명확.

### 소상공인에게 실제로 팔리는 가치 3가지

| 가치 | 현재 CTA | 개선 CTA |
|------|---------|---------|
| **모니터링 자동화** | "회원가입" | "매주 자동으로 AI 순위 체크" |
| **경쟁사 추적** | 없음 | "경쟁 가게가 AI에서 뜨면 즉시 알림" |
| **변화 측정** | "7일 후 확인" | "소개글 수정 후 2주 뒤 변화를 숫자로 확인" |

구독의 핵심 가치는 **"나 대신 매주 체크해주는 서비스"**다. 소상공인은 시간이 없다. 이 한 가지를 전면에 내세우면 된다.

## §9. 완료된 구현 내역 (2026-06-24)

### 9.1 진단 배경

§0.2의 세 가지 장벽 중 **신뢰 장벽**과 **효과 장벽**을 부분적으로 해소하는 작업을 먼저 진행했다.
§2의 대규모 퍼널 재설계(P0~P1)에 앞서 코드 내 기존 구조 안에서 즉시 적용 가능한 개선을 완료했다.

주요 오판 정정: "원인 설명이 없다"고 단정했으나 코드 확인 결과 `TodayOneAction.desc`에는 이미 원인 텍스트 존재.
실제 공백은 `ScoreBreakdownBox` 항목별 WHY 미표시 + 채널 타일 detail의 HOW-only 텍스트였다.

### 9.5 베이커리 업종 키워드 추천 신뢰도 개선 (2026-06-24, git `6e70259`)

#### 발단

Trial 스캔 결과 "키워드 추가하기" 섹션에서 베이커리 업체(예: "니재빵집")에게 `뷰 좋음`, `루프탑 있음`, `인스타 감성` 같은 **카페 공간 특화 키워드**가 추천됐다. 사용자는 "이건 내 가게랑 상관없는 키워드"로 인식 → **신뢰 장벽 발동** → 이탈.

#### 원인

`_CATEGORY_ALIASES`: `베이커리/빵집/베이커리카페` → `cafe` 카테고리로 일괄 분류.  
`cafe` taxonomy의 `공간분위기` 서브카테고리(가중치 0.25)에 `뷰 좋음`, `루프탑` 등이 포함됨.  
사용자 소개글에 해당 키워드가 없으면 자동으로 "누락 키워드"로 상위 추천됨.

#### 구현 상세

| 파일 | 변경 내용 |
|------|---------|
| `backend/services/keyword_taxonomy.py` | `bakery` 전용 taxonomy 신설 — 빵메뉴(30%), 재료품질(25%), 이용목적(20%), 공간분위기(15%), 운영정보(10%). `뷰 좋음`·`루프탑` 등 공간 키워드 제외. |
| `backend/services/keyword_taxonomy.py` | `_CATEGORY_ALIASES`: `bakery/베이커리/빵집/베이커리카페/제과/제과점/케이크샵/디저트` → `cafe` → **`bakery`** 분리 |
| `backend/routers/scan.py` | 사업장명 기반 안전 필터 추가 — 이름에 `빵/제과/베이커리/케이크` 포함 시 공간 키워드(`뷰 좋음`·`루프탑 있음`·`야외석 있음`·`인스타 감성`·`포토존`) 자동 제거. taxonomy alias 오분류 시 최후 방어선. |
| `backend/routers/scan.py` | `keyword_meta`에 `source: "업종_표준"` 필드 추가 (출처 추적용) |
| `frontend/components/trial/TrialKeywordRecommendCard.tsx` | `SUBCAT_LABEL`에 bakery 서브카테고리 추가 (`빵메뉴`, `재료품질`, `이용목적`, `공간분위기`) |
| `frontend/components/trial/TrialKeywordRecommendCard.tsx` | 키워드 출처 표시 문구 개선 — `"AI 추천 핵심 키워드"` → `"베이커리 소비자가 자주 검색하는 '빵메뉴' 키워드 — 노출 영향도 30%"` |

|--|--------|--------|

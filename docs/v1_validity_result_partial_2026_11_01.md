# V1 측정 타당성 검증 — 수기 결과 (진행 중, 2026-11-01)

> 프로토콜: `docs/v1_measurement_validity_protocol_2026_10_30.md`. 아래는 사용자가 공유한 ChatGPT 대화 링크를 브라우저로 열어 읽은 내용이다(제3자 입력, 로그인 여부·실행 시각은 화면에 없어 **미확인**).

## 1. 어니언 성수 (서울 성동구 성수동 · 카페) — 검색 켬(출처 이미지·링크가 붙은 답변), 각 질문 1회

공유 링크: `https://chatgpt.com/share/6ae6029d-4ca0-83ee-8117-2ffdee328a89` (대화 제목 "성수동 카페 추천")

| 질문 | 추천 순서 (7곳) | 어니언 성수 |
|---|---|---|
| Q1 `서울 성동구 성수동 성수 카페 추천` | 라에비뉴 성수 → 카페씨떼 성수 → ETF베이커리 성수 → 따우전드 성수점 → 로우키 성수 → 보카도버터 성수 → 카페 마트리 | **미포함** |
| Q4 `서울 성동구 성수동에서 성수 카페 잘하는 곳 추천해줘` | 로우키 성수 → **어니언 성수(2위, "성수 대표 카페")** → 대림창고 → 카페씨떼 성수 → 라에비뉴 성수 → 보카도버터 성수 → 카페 마트리 | **포함, 2위** |

- **인용 출처(카드 이미지 제목 기준)**: 다이닝코드(로우키·라에비뉴), Trip.com(카페씨떼·보카도버터·카페 마트리, 영문·일본어 페이지), 블로그·여행 사이트(Barrettish, Greysuitcase, 데이트팝, 도쿄 블로그, 네이버 블로그 아님). **네이버 지도·플레이스 출처는 보이지 않음**(카드 제목 기준, 링크 도메인은 확인하지 못함).
- 두 답변 모두 말미에 취향을 되묻는 후속 질문(대화형)이 붙었다.

## 2. 우리 기억 모드 기준값과 비교 (어니언 성수만)
- 기억 모드: 50회 중 25회 노출(약 50%, 2026-10-26).
- 검색 켬: 2회 중 1회 포함(Q1 미포함, Q4 포함·2위).
- **해석(방향성만)**: 어니언 성수가 검색 켬에서도 노출되는 경우가 있어 "기억 모드가 실제를 크게 과대 반영"한다는 신호는 아직 없다. 다만 1곳·질문당 1회라 괴리 판정 기준(5곳 중 2곳 이상)에는 한참 못 미친다.
- 인기 가게 어니언 성수가 한 질문에서 빠진 것은 **노출이 질문 표현과 실행마다 달라진다**는 뜻이라, 우리 점수의 "표본 N회 중 노출" 방식이 변동을 반영하는 것은 타당해 보인다(추정).

## 2-2. 힐링하우스마사지·홍뮤직스튜디오 — 검색 켬, 각 질문 1회 (두 번째 공유 링크)

공유 링크: `https://chatgpt.com/share/6ae603ac-5d88-83ee-ac80-81e64cc0e68e` (대화 제목은 "성수동 카페 추천"이지만 내용은 창원 마사지·편곡 — 제목이 잘못 붙은 것으로 보임). 첫 질문 문장은 화면에서 읽히지 않았다(답변은 "창원 상남동에서 마사지 잘하는 곳"으로 시작).

| 질문 | 추천 순서 | 우리 가게 |
|---|---|---|
| 마사지(첫 질문, 문장 미확인) | 청담더타이 창원상남점 → **힐링하우스 마사지(2위, 평점 5점·리뷰 6개 표시)** → 오하라스파 → 오감더타이스파 → 쿨스포츠마사지 | 힐링하우스마사지 **포함, 2위** (기억 모드 0/100) |
| Q1 `창원 편곡 추천` | 창원음악창작소 플레이스튜디오 → 라포뮤직 → **홍뮤직스튜디오 작곡교습소(3위)** → 뮤직아트컴퍼니 | 홍뮤직스튜디오 **포함, 3위** (기억 모드 0/50) |
| Q4 `창원에서 편곡 잘하는 곳 추천해줘` | **홍뮤직스튜디오 작곡교습소(1위, "우선 상담 추천")** → 라포뮤직 → 창원음악창작소 → 뮤직아트컴퍼니 | 홍뮤직스튜디오 **포함, 1위** |

- 인용 출처(카드 제목·링크): 당근 동네업체, 런즈(learns.academy), 숨고, 그라운즈, 핀다, 마맵, 구글 지도 형식 주소·평점. **네이버 출처는 보이지 않음**(도메인 전수 확인은 못 함).
- 편곡은 답변에 올라온 업체가 **4곳뿐**인 얇은 지역 시장이다.

### 의미 (예비 — 결론으로 쓰지 말 것)
- 기억 모드에서 0이던 두 가게가 검색 켬에서는 모두 올라왔다(1순위·2순위·3순위). 프로토콜의 판정 기준(기억 모드 0 → 검색 켬 등장)으로 보면 **5곳 중 2곳에서 괴리**라 "점수 보정 설계 착수" 기준선에 닿는다.
- 그러나 근거가 약하다: ①질문당 1회 ②**홍뮤직스튜디오는 사용자 본인 가게**이고 ChatGPT 개인화·메모리·로그인 영향 여부가 **미확인** ③편곡처럼 후보가 적은 시장은 가게가 하나만 있어도 올라오기 쉬움 ④힐링하우스는 구글 지도형 평점·주소 카드(출처가 구글 계열)로 보임.
- 따라서 지금 점수 모델을 바꾸지 않고, 아래 재검증으로 먼저 확인한다. 하라식당(인기 가게)과 대호흑돼지(대조군)가 결정적이다.

## 3. 남은 것
- **재검증 방법(권장)**: 로그아웃 상태 또는 시크릿 창에서(개인화·메모리 배제) 같은 질문을 반복.
- 어니언 성수 Q1·Q4 반복 2회씩, 하라식당·대호흑돼지·힐링하우스마사지·홍뮤직스튜디오 4곳 × Q1·Q4.
- 각 대화를 "공유" 링크로 보내 주면 같은 방식으로 읽어 이 문서에 누적한다(로그인 여부·실행 시각도 함께 적어 주면 좋다).

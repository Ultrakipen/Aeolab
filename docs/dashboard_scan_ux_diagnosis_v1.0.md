## 0. 한 줄 결론

**위치(position)는 문제가 아니다. 네이버 우선 배치는 옳다.**
문제는 **정보량이 아니라 ① 서열(hierarchy) ② 번역(우리 용어→사장님 언어)** 두 가지다.
정보는 충분하고 가치도 있는데, 같은 비중 카드가 너무 많아 "무엇이 중요한지"가 안 보이고, 내부 분류 용어를 사용자에게 그대로 떠넘기고 있다.

## 2. 사용자 관점 핵심 문제 3가지

### 문제 ① — "네이버에 잘 나와?" 하나의 질문을 3개로 쪼개 돌려줌
- 코드: `DashboardInsightZone.tsx:192~204` — `sectionBriefing` / `sectionNaverSearch` / `sectionAiTab` 3개 카드가 각각 독립 상태배지(✓/✗/–)를 단다.
- 사장님 머릿속 질문은 단 하나 — **"내 가게 네이버에 잘 떠?"**
- `AI브리핑 / AI탭 / 일반검색`은 **우리 내부 taxonomy**지 사장님 언어가 아니다.
- 특히 `naverAiTabVisible === null`일 때 "측정 준비 중(–)" 표기(`DashboardInsightZone.tsx:116,123`) — 3채널 중 둘이 "–"면 사장님은 **"그래서 좋다는 거야 나쁘다는 거야?"** 가 된다.
- → **체감 복잡도의 1순위 원인.**

### 문제 ② — "오늘 할 일"이 3곳에 흩어짐
- Hero 안 `todayAction` (`DashboardScoreZone.tsx:78`)
- 별도 ⑤ 오늘 할 일 섹션 (`page.tsx:520` `DashboardActionZone`)
- /guide 페이지
- 같은 `todayTasks` 배열을 Hero와 ActionZone이 동시에 받음(`page.tsx:412, 527`). 행동 지시가 한 곳에 모이지 않아 **"결국 뭘 하라는 거지?"** 가 된다.

### 문제 ③ — 돈 낼 가치의 '증거'가 접혀 있음
- 차별적 가치 = **내 가게가 ChatGPT에 실제 인용된 문장 / 경쟁사 대비 내 위치 / 키워드 실측 순위**
- 그런데 이건 ⑥ 상세분석·⑦ 글로벌 — **접힌 섹션** 안에 있다(`page.tsx:537, 589` `defaultOpen` 없음 = 접힘).
- 펼쳐야 보이는 실측 증거가 "이 서비스 돈값 하네"를 만드는 가장 강한 무기인데 숨어 있다.
- 반대로 ③ 네이버 현황은 "준비 중(–)" 표기가 많을 수 있어, **펼친 곳엔 빈 신호가, 접힌 곳엔 강한 증거가** 배치된 역전 상태.

## 3. "돈 낼 만한 정보가 있는가?" — 솔직한 답

**있다. 단, 지금 화면은 그 가치를 약하게 전달한다.**

- 실제 보유한 가치 자산(실측):
  - ChatGPT·Gemini 실제 인용문 (Track2, 50~100회 샘플링)
  - 경쟁사 대비 순위·키워드 갭
  - 네이버 일반검색 실측 노출·리뷰/사진/소개글 진단
  - AI 맞춤 소개글·톡톡 메뉴 **생성 산출물**(받아가는 것)
- 문제는 가치 자체가 아니라 **전달 서열**. 강한 증거가 접혀 있고, "준비 중" 신호가 펼쳐져 있다.

---

## 4. 디자인·위치 문제인가? — 직접 답

- **위치(섹션 순서): 문제 아님.** 네이버 최상단 → 글로벌 하단(접힘)은 한국 소상공인 심리(네이버 신뢰·민감도)에 정확히 맞다. 유지 권장.
- **디자인(시각): 부차적.** 카드 스타일 자체보다 "모든 카드가 같은 시각 비중"인 게 문제다.
- **진짜 원인: 정보 서열 + 용어 번역.** 정보를 빼는 작업이 아니라 **서열을 다시 매기는 작업**(CLAUDE.md "유용한 기능 제거 금지" 원칙과 충돌 없음).

## 5. 권장 개선 방향 (구현 보류 — 향후 착수 시 우선순위)

### 레버 A (효과 최대) — Hero를 "한 문장 평결 + 1개 행동"으로 압축
```
○○님 가게는 지금 네이버에서 '보통' 수준이에요.
가장 시급한 건 → 소개글에 '△△' 키워드 추가입니다.
(작게) 글로벌 AI: 양호
```
- Hero 신호 8개 → 핵심 1평결 + 1행동 + 보조 1줄로 강등.

### 레버 B — 네이버 3채널 카드를 1개 "네이버 노출 현황" 통합카드로
- 브리핑/AI탭/일반검색은 통합카드 안의 **작은 줄(line)**로 강등.
- 사장님은 "종합 상태" 먼저 → 궁금하면 펼쳐서 채널별 확인.
- `DashboardInsightZone.tsx` 3-section 구조를 1 summary + 펼침 detail로 재배치.

### 레버 C — 실측 증거 미리보기를 상단으로
- ⑥ 상세·⑦ 글로벌 안의 **AI 실제 인용문·경쟁사 순위 1줄**을 Hero 직하단에 미리보기로 노출.
- "돈값" 체감 강화.

### 레버 D — "오늘 할 일" 단일화
- Hero 안 액션과 ⑤ ActionZone 중복 제거 → 행동 지시 한 곳 집중.

### 우선순위 제안
1. A (Hero 압축) — 체감 개선 가장 큼
2. B (네이버 통합카드) — 복잡도 감소 핵심
3. D (오늘 할 일 단일화) — 빠른 정리
4. C (증거 끌어올리기) — 가치 전달 강화

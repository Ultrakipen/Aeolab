# 네이버 확인 지연·중단 시 고객 소통 문안 (T-6 / W-3, 2026-11-02)

> 상태: **초안 — 사용자 승인 전. 발송·게시하지 않았다.** 알림톡이 아니라 공지사항·배너·이메일이므로 템플릿 승인은 필요 없다.
> 보상 기준은 결정 D-3(제안값: 3일 이상 불가 시 일할 연장, 7일 이상 시 환불 선택권)을 그대로 반영했으며 **제안값이지 확정이 아니다.**

## 원칙
- 사실만 쓴다. **원인을 추정하지 않는다**("네이버가 차단했다" 같은 표현 금지 — 차단인지 화면 변경인지 한도인지 확인되기 전에는 모름).
- 점수·순위는 0이나 '미노출'이 아니라 **마지막 확인값 + 날짜 또는 '확인 전'** 으로 남아 있음을 알린다.
- 복구 시점을 약속하지 않는다("곧", "내일 중" 단정 금지). 알려줄 수 있는 것은 "다시 시작되면 자동으로 새 값으로 갱신".
- 계속 동작하는 것(ChatGPT·구글 측정, 콘텐츠 초안 도구, 이미 만든 가이드)을 함께 알린다.
- 개선 효과·보상 외의 보장 표현 금지.

## 단계별 문안

### 0단계 — 시스템 자동 배너 (이미 구현, `services/naver_status.py`)
| 상태 | 문구 |
|---|---|
| 지연(쿨다운) | 네이버 확인이 지연되고 있어요. {예상 시점} 다시 확인될 것으로 예상돼요. |
| 오늘 한도 | 오늘은 네이버 확인 요청이 많아 일부 항목은 내일 확인될 예정이에요. |
| 수동 중단(킬스위치) | 네이버 확인을 잠시 멈춰 두었어요. 다시 시작되면 새 값으로 갱신돼요. |
| 재개 중 | 네이버 확인을 다시 시작하는 중이에요. 다음 측정 때 새 값으로 갱신돼요. |

### 1단계 — 24시간 이상 지연: 공지사항 (게시 위치 `notices` 테이블)
- 제목: 네이버 확인이 지연되고 있어요
- 본문: 현재 네이버를 직접 확인하는 항목(검색 순위·스마트플레이스 상태·AI 브리핑 등)의 확인이 지연되고 있으며, 블로그 진단과 경쟁사 정보 갱신도 늦어질 수 있습니다. 이 항목들은 **0점이나 '미노출'로 바뀌지 않고** 마지막으로 확인한 값과 날짜가 그대로 표시됩니다. ChatGPT·구글 측정과 소개글·블로그 초안 도구는 평소처럼 사용하실 수 있습니다. 확인이 다시 시작되면 자동으로 새로 측정해 갱신합니다. 진행 상황은 이 공지에 계속 업데이트하겠습니다.

### 2단계 — 3일 이상 불가: 구독자 이메일 (제목·본문)
- 제목: [AEOlab] 네이버 항목 확인 지연 안내와 이용 기간 연장
- 본문: 안녕하세요, AEOlab입니다. {시작일}부터 네이버 쪽 측정 항목을 확인하지 못하고 있으며, 블로그 진단·경쟁사 정보 갱신 같은 일부 기능도 늦어질 수 있습니다. 원인은 확인 중이며, 확인되기 전에는 추정해서 말씀드리지 않겠습니다. 그동안 네이버 항목은 마지막 확인값({날짜})으로 표시되며 새 결과로 오해되지 않도록 '확인 전' 또는 날짜를 함께 보여 드리고 있습니다. 다른 기능은 정상입니다. 확인하지 못한 기간만큼 이용 기간을 **일할 연장**해 드리겠습니다(별도 신청 불필요). 문의는 support@aeolab.co.kr.

### 3단계 — 7일 이상 불가: 환불 선택권 추가 문안
- 위 2단계 본문 끝에 추가: 네이버 항목 확인이 7일 이상 이어지지 않아, 원하시면 **남은 기간 환불**을 선택하실 수 있습니다. 회신 주시면 처리해 드립니다.

### 4단계 — 복구 안내 (공지 업데이트 + 이메일)
- 네이버 항목 확인이 다시 시작되었습니다. 다음 측정부터 새 값으로 갱신되며, 복구 직후에는 값이 평소와 다르게 보일 수 있으니 **측정 시점·기기·로그인 상태에 따라 달라질 수 있습니다.** 연장된 이용 기간은 {날짜}까지입니다.

## 운영자 체크리스트
1. 킬스위치/회로 상태·`GET /api/status/naver`로 사실 확인(원인 단정 금지).
2. 24h → 공지 게시 / 72h → 이메일+연장 / 168h → 환불 선택권 문구 추가.
3. 연장·환불 대상은 `scan_scheduling.entitled_user_ids` 기준 유효 구독자.
4. 복구 후 공지 업데이트, 재측정 우선 큐 확인.

## 검토 반영 (2026-11-02)
코드·약관과 대조해 고친 것(커밋은 git 로그 참조):
- **배너 부가 문구에서 Gemini 제거** — `naver_status.py KEEP_NOTE`가 "ChatGPT·Gemini 등 AI 검색 측정은 그대로 진행돼요"라고 말했으나 `GEMINI_MEASUREMENT_LIVE=false`(공개 화면 '준비 중')라 사실이 아니었다 → "ChatGPT·구글 AI 검색 측정"으로 정정. 네이버 항목은 기능마다 접속 지점이 달라 "네이버를 직접 확인하는 항목"으로 일반화.
- **재개 시점은 '예상'으로** — 배너가 "{시점} 다시 확인돼요"로 단정했으나 원칙(복구 시점 약속 금지)과 어긋나 "다시 확인될 것으로 예상돼요"/"내일 확인될 예정이에요"로 완화(`tests/test_naver_status_copy.py`).
- **영향 범위 보강** — 네이버 접속 지점은 순위(`naver_keyword_rank`)·블로그 진단(`blog_search_analyzer`, 검색 화면 접속 확인)·전후 스크린샷·경쟁사 정보 등으로 문서 초안의 나열보다 넓다. 공지 1·2단계 본문에 블로그 진단·경쟁사 정보 갱신 지연 가능성을 추가.

**아직 사용자 결정·작업이 남은 것**
- **보상 정책 ↔ 약관**: 약관 제5조는 청약철회 기간(7일) 경과 후 잔여 기간 환불을 제공하지 않는다고 하고, 제8조는 일시 중단을 "사전 또는 사후 고지"만 규정한다. 이 문서의 일할 연장(3일↑)·환불 선택권(7일↑)은 약관보다 유리한 자발적 정책이므로, 약관·FAQ에 근거를 두거나 "회사 정책이며 변경될 수 있음"으로 명시할지 결정 필요(법률 판단은 별도). 3일·7일은 제안값.
- **운영 도구 공백**: 구독자 이메일 발송(대상 추출·드라이런), 일할 연장 적용, 환불 처리 절차가 준비돼 있지 않다(현재 활성 구독이 적어 수동 가능, 소프트 런치 전 준비 권장).
- 24h·72h·168h 판단은 운영자 수동 — 자동 경과 시간 계산은 없음.

## 3. 신뢰 규칙(작업 지침 7번 적용)

- 입력이 비어 있으면 0이 아니라 "입력 대기" 안내(가짜 결과 없음). 배달 계산기는 수수료율이 비어 있으면 계산하지 않는다(0%와 입력 안 함을 구분).
- 모든 기준값에 출처 링크·확인일·적용 연도 표기(`BasisNotice`). **적용 연도(`validThrough`)가 지나면 방문 시점 기준으로 경고**하고, "2026 최저임금 입력" 버튼을 숨기며 최저임금 미달 판정을 하지 않는다(옛 기준으로 단정 금지, `useClientValue`로 ISR 캐시와 무관하게 판정).
- 결과는 "추정·개략"으로 표기, 면책 문구 공통(세무·노무 상담 대체 아님, 실제 세액·보험료·정산액은 국세청·공단·정산서 확인).
- 경고 문구는 완화형, 효과·보장·절세 약속 없음.

## 4. 검증

- `npm run test:calc`(Node 내장 테스트 + TypeScript 변환): 18건 — 기대값은 **독립 손계산**(예: 건강보험 사업주 분 2,156,880×7.19%÷2=77,540원; 암산 77,545원은 틀렸었음). 간이과세 예시는 4,800만원×15%×10%=**72만원**(검색 요약의 720만원은 산술 오류).
- **변이 검증 6종**(−0 방지 제거 / 장기요양 절반 누락 / 기준연도 만료 판정 제거 / 시행 연도 고정 / 수수료율 범위 검사 제거 / 퇴직금 상시 포함) 모두 테스트가 실패해 잡음, 원복 후 동일.
- 시험이 잡은 실제 결함: 고정비 0일 때 손익분기 수량이 `-0`, 이익이 −0.4원일 때 `-0`, 비율에 부동소수점 잔여(28.199999999999996) → 수정.
- 프로덕션 빌드·실제 브라우저(PC/모바일)에서 4개 계산기를 입력해 손계산 기대값과 일치 확인, 초기·부분 입력에서 결과 카드 0개 확인, 브라우저 시계를 2026·2027·2028로 고정해 최저임금 자동 전환·판정 중단 확인, 백엔드 전체 테스트 통과, 타입 검사·린트 오류 0.
- **점검에서 추가로 잡은 것(11-16):** 랜딩 상단 메뉴에 `/area`·`/tools` 링크를 lg에 넣었더니 1024px에서 가로 넘침(문서 폭 1167px) → `xl`(1280px 이상)로 변경해 1024·1100·1280·1440px 넘침 없음 확인 / 2027 최저임금 공식 고시 확인 후 연도별 표 추가(2027-01-01에 계산기가 멈추는 문제 예방) / 퇴직금 옵션·연차수당·상여 미포함 안내 / 수수료율 100% 초과·주 168시간 초과·기타 보험률 범위 검사 / 입력 12자리 제한(지수 표기로 깨지는 것 방지) / 계산기 간 이동 링크 / CTA 클릭 측정(TrackedCTA, location=tools) — 하단 AEOlab 홍보 상자는 사용자 결정(11-16)으로 제거됨.

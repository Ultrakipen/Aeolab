## 1-보강. 코드만 수정 — 재신청 불필요, 2026-07-20 배포 완료 (3개)

> 승인 문안 원문을 대조한 결과 아래 3개는 문안 자체는 코드와 일치하고, **날짜류 변수 하나를 코드가 채우지 않고 있던 것**이 유일한 문제였습니다. 문안 변경이 없으니 비즈센터 재신청 없이 코드만 고치면 됩니다 — `kakao_notify.py`에 `#{확인일시}`/`#{기준일}`을 발송 시점 날짜(`date.today()`)로 채우도록 수정·배포 완료.

| 템플릿 | 누락 변수 | 함수 | 상태 |
|--------|----------|------|------|
| `AEOLAB_CITE_01` | `#{확인일시}` | `send_ai_citation()` (`kakao_notify.py:205`) | 수정 완료 |
| `AEOLAB_COMP_01` | `#{확인일시}` | `send_competitor_change()` (`kakao_notify.py:219`) | 수정 완료 |
| `AEOLAB_ACTION_01` | `#{기준일}` | `send_action_items()`/`send_post_remind()` (`kakao_notify.py:230`) | 수정 완료(§6 참조) |

**패턴 정리(갱신):** 승인된 5종 핵심 알림 전부(SCORE_01·CITE_01·COMP_01·NEWS_01·ACTION_01)가 하나같이 "날짜/시각" 계열 변수를 요구하는데 코드가 값을 채운 적이 없었습니다 — 최초 템플릿 설계 시 넣었던 타임스탬프 변수를 구현 단계에서 빠뜨리는 동일한 실수가 5번 반복된 것. 이 중 3개(CITE_01·COMP_01·ACTION_01)는 그 변수 하나가 유일한 문제라 코드 수정만으로 해결됐고, 나머지 2개(SCORE_01·NEWS_01)는 점수 숫자 노출 등 별도 문제가 겹쳐 있어 문안 자체를 재신청해야 합니다(§1).

**⚠️ 확인 필요(불변):** 위 수정은 "누락 변수를 채우면 정상 발송될 것"이라는 추정에 근거합니다. 실제로 NHN이 변수 누락 시 요청 자체를 거부하는지, 빈 값으로 관대하게 처리하는지는 공식 스펙으로 확인하지 못했습니다 — 배포 후 실제 발송 성공 여부는 콘솔 발송 이력으로 확인 필요.

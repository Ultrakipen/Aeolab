# V1 측정 타당성 검증 프로토콜 (2026-10-30)

> 목적: **우리 ChatGPT 측정(검색 없는 "기억 모드")이 실제 소비자가 보는 화면(검색을 켠 AI 답변)과 얼마나 다른지** 확인한다. 개발 없음, 네이버 접속 없음, 점수에 반영하지 않음.
> 근거 설계: `docs/naver_independence_design_v2.0_final_2026_10_29.md` §1-5, §6-2 (V1).
> 표기: **[확인]** 이 세션에서 서버 조회·실행으로 확인 / **[제안]** 근거 없는 설계값 / **[미확인]**.

---

## 1. 왜 하는가
- 유료 스캔 새 프로브(`recommend_v1`) 기준 ChatGPT 노출은 5개 가게 중 1곳(어니언 성수)만 있고 나머지는 0이다 [확인]. 이 "0"이 가게의 실제 상태인지, 검색 없는 측정 방식의 한계인지 모른다.
- 외부 연구(Oxford, 상품 프롬프트, 관찰 연구)에서 검색 켬/끔에 따라 추천이 80.2%의 비교에서 달라졌다 [외부, 로컬은 미확인].
- 결과에 따라: 괴리가 크면 점수·화면 문구 보정이 필요하고(지침 9, 인기 가게 저평가), 괴리가 작으면 현행 해석을 유지한다.

## 3. 질문 (우리 스캔과 동일한 문장 — 가게 이름을 넣지 않는다)
| 가게 | Q1 (짧은 질의) | Q4 (긴 자연어) |
|---|---|---|
| 1 어니언 성수 | 서울 성동구 성수동 성수 카페 추천 | 서울 성동구 성수동에서 성수 카페 잘하는 곳 추천해줘 |
| 2 하라식당 본점 | 창원 일본가정식 추천 | 창원에서 일본가정식 잘하는 곳 추천해줘 |
| 3 대호흑돼지 | 창원 동태탕 추천 | 창원에서 동태탕 잘하는 곳 추천해줘 |
| 4 힐링하우스마사지 | 창원 상남동마사지 추천 | 창원에서 상남동마사지 잘하는 곳 추천해줘 |
| 5 홍뮤직스튜디오 | 창원 편곡 추천 | 창원에서 편곡 잘하는 곳 추천해줘 |
(나머지 질의 3개도 `scan_results.chatgpt_result.queries_used`에 있다. 우선 Q1·Q4 두 개만 확인한다 [제안].)

## 4. 실행 방법
**Tier 1 (필수, 약 20~30분)**: ChatGPT에서 **웹 검색을 켠 상태**로 5곳 × Q1·Q4 = 10개 질문.
**Tier 2 (선택)**: 같은 질문을 Gemini 앱(검색 포함 기본)과 구글 AI 모드/AI Overview에서도.
- 질문마다 **새 대화**로 시작하고, 같은 질문을 **3회 반복**한다 [제안] (답변이 매번 달라진다). 시간이 없으면 1회씩만 해도 방향은 볼 수 있다.
- 로그인 상태(로그인/비로그인), 위치, 날짜·시각을 기록한다. 개인화와 위치에 따라 달라질 수 있다.
- 기록할 것: 추천된 가게를 **순서대로 최대 5개**, 우리 가게 포함 여부와 순위, **인용된 출처 링크(어느 사이트)**, 메모. 서식: `docs/v1_validity_record_template.csv`(엑셀에서 열어 입력).
- 질문에 가게 이름을 **넣지 않는다**(우리 측정과 같은 방식).
- 이 검증은 네이버에 접속하지 않으며 AEOlab 점수·알림에 반영되지 않는다.

## 5. 판정 기준 [제안 — 표본이 작아 방향성만]
| 상황 | 의미 | 조치 |
|---|---|---|
| 기억 모드 0 → 검색 켬에서도 0 (가게 5곳 중 대부분) | 현재 측정이 실제를 대체로 반영 | 현행 해석 유지, 문구 강화 정도 |
| 기억 모드 0 → 검색 켬에서 **3회 중 1회 이상 등장** | 현재 점수가 실제 노출을 **과소 반영** | 점수 표현·설명 보정 설계(지침 9, 별도 승인) |
| 기억 모드 노출 → 검색 켬에서는 안 나옴 (어니언 성수) | 기억 모드가 실제를 **과대 반영** | 문구·표현 보정 |
| 검색 켬에서 출처가 구글·Bing·특정 플랫폼에 몰림 | 노출 레버 후보 단서 | 별도 분석(N3/V2 참조표와 대조) |
**결정 규칙**: 5곳 중 괴리(위 2·3행) **2곳 이상** → 점수 모델 보정 설계 착수. 0~1곳 → 현행 유지. 하나라도 인기 가게(하라식당·어니언 성수)에서 괴리가 나오면 우선순위를 높인다.

## 6. 한계 (결과를 해석할 때)
- 가게 5곳, 질의 2개, 반복 3회: 통계적 결론이 아니라 **방향성**이다.
- 사람이 직접 하는 소비자 화면은 개인화·로그인·지역·시각의 영향을 받는다.
- 관리자 소유 사업장이 포함돼 있어 일반 사장님의 상황을 대표하지 않을 수 있다.
- ChatGPT의 검색 구성(Bing, 스크래핑된 구글 결과, 자체 인덱스 혼합)은 비공개이고 계속 변한다 [외부].

## 7. 선택: 자동화 보조 (승인 필요, 아직 하지 않음)
OpenAI API의 웹 검색 도구로 같은 질문을 반복 실행하면 수기 부담이 줄지만 ① 단가가 출처마다 상충($10~$50/1,000회, 숨은 하위 검색 과금 사례) [미확인] ② 소비자 ChatGPT 앱과 완전히 같지 않을 수 있다 ③ 새 API 사용이다. 수기 결과를 본 뒤 필요할 때만 소규모로 제안한다.

## 8. 결과 전달 방법
CSV를 채운 뒤 알려주시면 가게별 기억 모드(0/50 등) 대비 검색 켬 노출, 괴리 판정, 인용 출처 분포를 집계해 `docs/v1_validity_result_YYYY_MM_DD.md`로 정리한다.

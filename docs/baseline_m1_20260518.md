## 1. 캡처 SQL

> **컬럼 매핑** (DB ↔ 모델 엔진 v3.0 명칭)
> - `scanned_at` = 스캔 시각 (`created_at` 아님 — 2026-05-18 정정)
> - `naver_channel_score` ≈ Track1 (네이버 채널)
> - `global_channel_score` ≈ Track2 (글로벌 AI)
> - `total_score` ≈ unified_score

```sql
-- 1) 최근 7일 스캔 결과 요약 (베타 사용자 전체)
SELECT
  business_id,
  ROUND(naver_channel_score::numeric, 1)  AS track1,
  ROUND(global_channel_score::numeric, 1) AS track2,
  ROUND(total_score::numeric, 1)          AS unified,
  (naver_result->>'in_briefing')::bool       AS in_briefing,
  (naver_result->>'in_ai_tab')::bool         AS in_ai_tab,
  (naver_result->>'ad_only')::bool           AS ad_only,
  (naver_result->>'blogMentionCount')::int   AS blog_count,
  scanned_at
FROM scan_results
WHERE scanned_at >= NOW() - INTERVAL '7 days'
ORDER BY scanned_at DESC
LIMIT 50;

-- 2) Track1·Track2 점수 분포 (업종별)
SELECT
  b.category,
  COUNT(*) AS n,
  ROUND(AVG(s.naver_channel_score)::numeric, 1)  AS avg_track1,
  ROUND(AVG(s.global_channel_score)::numeric, 1) AS avg_track2,
  ROUND(AVG(s.total_score)::numeric, 1)          AS avg_unified
FROM scan_results s
JOIN businesses b ON b.id = s.business_id
WHERE s.scanned_at >= NOW() - INTERVAL '30 days'
GROUP BY b.category
ORDER BY n DESC;

-- 3) in_briefing / in_ai_tab 노출률
SELECT
  COUNT(*) AS total_scans,
  SUM(CASE WHEN (naver_result->>'in_briefing')::bool THEN 1 ELSE 0 END) AS briefing_hit,
  SUM(CASE WHEN (naver_result->>'in_ai_tab')::bool THEN 1 ELSE 0 END)   AS ai_tab_hit,
  SUM(CASE WHEN (naver_result->>'ad_only')::bool THEN 1 ELSE 0 END)     AS ad_only_count
FROM scan_results
WHERE scanned_at >= NOW() - INTERVAL '30 days';
```

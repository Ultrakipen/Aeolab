사용 순서

  1. ① 서비스 제목 → ② 서비스 설명 → ③ 서비스 제공 절차 → ④ 가격 입력 → ⑤ 메인·상세 이미지 순서로 입력합니다.
  2. ②와 ③은 아래 복사 버튼을 누른 뒤, 크몽 편집기를 클릭하고 Ctrl+V로 붙여넣습니다. (이 버튼은 편집기가 받는 형식 그대로 복사합니다)
  3. 붙여넣은 뒤 줄이 달라 보이면 아래 「직접 복사용 HTML」 칸이 아니라 이 파일의 설명을 다시 알려주세요.

크몽 편집기 제한: 최소 100자, 최대 20,000자, 특수문자 < 와 ` 사용 불가 · 번호/글머리 목록 기능 없음(항목마다 문단으로 분리). 상세 이미지는 본문이 아니라 별도 「상세 이미지」 칸에 올립니다.

# 반경 300m 업종 분포(/area)와 매출·이익 목표 계산기(/tools/sales-target) — 2026-11-20

## 1. 왜 바꿨나
사용자 지적: 구/시 단위는 "내 가게 중심"이 아니고, 업종 11개 묶음(음식점·미용 등)은 너무 포괄적이라 정보 가치가 없다.

## 2. 반경 300m 업종 분포
- 데이터: 소상공인시장진흥공단 상가(상권)정보 `storeListInRadius`(data.go.kr, 기존 `SBIZ_API_KEY`). 업종 코드로 거르지 않고 **반경 안 전체 업소를 1,000건씩 받아 소분류 이름별로 직접 센다**(실호출 2026-11-20: 성수 1,640 · 강남역 3,358 · 창원 상남 772곳, 소분류 124~140종, 응답 0.25초, 기준월 2026-09).
- 위치: 카카오 주소검색 → 없으면 키워드검색으로 후보 최대 5곳을 보여 주고 방문자가 고른다(`/api/area/locate`). 브라우저 현재 위치도 가능. 결과 `/api/area/nearby?lon&lat`(집계만 — 가게 이름·주소·상가 ID 없음, 좌표·검색어 저장 안 함).
- 방문자 요청마다 외부 API를 부르므로(스냅샷 불가) 보호 5종: 같은 좌표 24시간 캐시(일부만 센 결과는 캐시 안 함) · 동시 2건 · IP당 분당 12회 · **IP당 하루 신규 좌표 40곳**(`AREA_NEARBY_IP_DAILY_MISSES`, 캐시 적중은 안 셈) · 하루 총 호출 1,500회(`AREA_NEARBY_DAILY_CALLS`, 수집 스크립트와 같은 키 한도 보호) · 요청 전체 25초 상한. 좌표는 소수 5자리(≈1m) 반올림만 쓴다 — 거칠게 맞추면 "내 가게 중심"이 어긋난다(보안 자동 검토의 "100m 격자" 제안은 이 이유로 채택하지 않고, 나머지 제안은 반영).
- 한계(화면에 명시): 등록 업소 수일 뿐 영업 여부·매출은 모름 · 이 API에 폐업 정보가 없어 **반경 300m 폐업 현황은 제공하지 않음**(구·시 단위 누적 폐업은 기존 지역 선택) · 직선거리 원 · 기준월 지연 · 호출 실패는 0곳이 아니라 "집계할 수 없음"으로 표시 · 받은 수가 전체 수보다 적으면 "적게 집계됐을 수 있음".
- 예산 카운터·캐시는 프로세스 메모리(워커 1개 전제) — 재시작하면 초기화된다. 워커를 늘릴 때는 공유 저장소로 옮길 것(`docs/backend_worker_scaling_trigger_v1.0.md`).
- 파일: `backend/services/area_nearby.py`·`routers/area.py`·`tests/test_area_nearby.py`(12건, 변이 검증 7종), `frontend/lib/areaNearby.ts`·`app/(public)/area/NearbyPanel.tsx`·`tests/nearby.test.mjs`.
- **미확인**: 개인 번호가 들어간 한 번지 주소 검색의 실제 일치율(도로명만 입력하면 후보가 안 나올 수 있음 — "경남 창원시 성산구 중앙대로114번길" 전체 문자열은 후보 0건이었고 "창원시청"·"창원 상남동 중앙대로"는 정상), 실제 사장님 사용성, 소상공인365 승인 조건과의 충돌 여부.

## 3. 매출·이익 목표 계산기
- 입력: 판매가·원가(1개당)·수수료율(선택)·한 달 고정비(선택)·판매 개수(선택)·목표 순이익(선택)·영업일수(선택).
- 출력: 1개당 이익·마진율 / N개를 팔면 매출·원가·수수료·(고정비 입력 시) 순이익 / 목표 순이익을 내려면 몇 개(올림)·매출·하루 기준. 1개당 이익이 0 이하면 개수를 만들지 않고 "채울 수 없음".
- 식: 1개당 이익 = 판매가 − 원가 − 판매가×수수료율, 순이익 = 개수×1개당 이익 − 고정비, 필요 개수 = ceil((목표+고정비)/1개당 이익). 세금 미반영·판매량 변화에 따른 가격·손님 변화 미반영을 화면에 적음.
- 시험: `lib/calc` `salesTarget` 손계산 기대값(4,500원·원가 1,340원: 100개→남는 돈 316,000, 수수료 3%+고정비 100만→순이익 −697,500, 고정비 200만+목표 100만→950개/4,275,000원/하루 37개)과 변이 3종, 라이브 화면 값 일치(998,840원·950개·4,275,000원·37개).

## P1 — 중요 수정 사항 (당일 수정 권장)

### P1-1. 요금제 페이지 — 네이버 AI탭 "베타" 오표기
**파일**: `frontend/app/(public)/pricing/page.tsx`  
**위치**: 요금제 채널 비교표 "네이버 AI 탭" 행

**문제**: 채널 상태를 "베타 · 확대 진행 중"으로 표기함.  
그러나 **2026-06-25 정식 출시** 완료됨 (홈페이지에도 "2026-06-25 정식 출시 (네이버 공식)" 명기됨).

**현재 표기**: `"베타 · 확대 진행 중 · 콘텐츠 품질에 따라 다름"`  
**수정 필요**: `"정식 출시 · 콘텐츠 품질에 따라 다름"` 또는 `"2026-06-25 정식 출시 · 콘텐츠 품질에 따라 다름"`

**영향**: 정식 출시된 기능을 "베타"로 안내하면 소상공인이 불안정한 서비스로 오인. 요금제 가입 결정에 영향.

**오판 검증**: 홈페이지 텍스트에 "2026-06-25 정식 출시 (네이버 공식)"이 있고, CLAUDE.md에도 "2026-06-25 전체 네이버 사용자 정식 출시 완료" 명기. 반증 없음 — P1 확정.

### P1-2. 모든 공개 페이지 Footer — 서비스 설명 불일치
**파일**: footer 컴포넌트 (공개 페이지 전체)  
**위치**: Footer 로고 하단

**문제**: Footer에 "네이버 AI 브리핑 노출 관리 서비스"로 표기됨.  
그러나 현재 서비스는 **네이버 AI탭 + ChatGPT + Gemini + Google AI + 일반 검색** 까지 다루는 멀티채널 서비스.

- 실제 서비스 범위: 네이버 AI 브리핑 + AI탭 + ChatGPT + Gemini + Google AI + 네이버 일반검색 상위노출
- Footer 설명: "네이버 AI 브리핑 노출 관리 서비스" (단일 채널 표현)

**소상공인 관점 문제**: AI 브리핑 비대상 업종 소상공인이 "이건 나한테 해당 안 되겠네"라고 이탈할 수 있음.

**수정 제안**: `"AI 검색 노출 관리 서비스"` 또는 `"네이버 · AI 검색 노출 관리 서비스"`

**오판 검증**: 홈페이지 헤드라인은 "AI 검색 준비도 진단 서비스 — AI브리핑·AI탭·SEO·ChatGPT"로 훨씬 넓게 표기. Footer만 좁게 표기. 불일치 확정.

### P1-3. 대시보드 "개선 후 반영 예상 기간" — Gemini 표기 불통일
**파일**: `frontend/app/(dashboard)/dashboard/` (대시보드 사이드바 또는 카드 컴포넌트)  
**위치**: 검색 키워드 선택 영역 하단 "개선 후 반영 예상 기간"

**현재 표기**:
```
· Gemini: 수 주~수개월 (Google 검색 실시간 연동)
```

**홈페이지 preview 섹션 표기**:
```
Gemini — Google 실시간 검색 연동: 수 주 / 학습 데이터: 수개월~1년
```

**문제**: Gemini는 실시간 검색 연동(수 주~수개월)과 학습 데이터(수개월~1년) 두 경로가 있음.  
대시보드에는 실시간 경로만 표기, 홈에는 두 경로 구분 표기 — 불일치.

**수정 제안 (대시보드)**:  
`· Gemini: 수 주~수개월 (Google 실시간 연동 기준, 학습 데이터 반영은 수개월~1년 별도)`

**오판 검증**: CLAUDE.md에 "(Google Search 실시간 grounding — GBP 인덱싱 1~4주 후 연동)" 명기. Gemini는 두 경로가 구분됨. 공식 Google 문서에서 구체 기간 미명시이므로 "추정" 표기 유지 맞음.

### P1-4. 대행 서비스 02번 — "AI 브리핑 친화 최적화" 업종 무관 표기
**파일**: `frontend/app/(dashboard)/delivery/page.tsx`  
**위치**: "02 AI 검색 최적화" 서비스 항목

**현재 표기**:
```
✅ AI 브리핑 친화 최적화
✅ 소개글·톡톡채팅방 메뉴 최적화
✅ 후기 답글 10건 작성
✅ 핵심 키워드 보강
```

**문제**: 테스트 계정 홍스튜디오(사진·영상 = INACTIVE 업종)에도 "AI 브리핑 친화 최적화"가 동일하게 표시됨.  
AI 브리핑 비대상 업종 소상공인이 "AI 브리핑 최적화 대행" 비용을 지불하고 효과가 없다는 것을 나중에 알 수 있음.

**수정 제안**: 
- 업종별로 표기 분기 (ACTIVE 업종: "AI 브리핑 친화 최적화", INACTIVE: "AI탭·ChatGPT 최적화")
- 또는 현재 표기에 "(AI 브리핑 대상 업종 기준, 비대상 업종은 AI탭·ChatGPT 최적화로 진행)" 주석 추가

**오판 검증**: 대행 서비스는 업종 무관으로 표시되는 것을 직접 확인. 소상공인 혼란 가능성 실재.

## P2 — 개선 권장 (이번 주 내)

### P2-1. ChatGPT 광고 대응 (`/ad-defense`) — "Q2" 시기 문구 만료
**문제**: "2026 Q2 광고화 대비" 문구 사용 중. 현재 2026-06-26 (Q2 종료 임박).  
**수정**: "2026 하반기 대비" 또는 "AI 검색 광고화 대비"로 변경.

---

### P2-2. 설정 페이지 (`/settings`) — 과도한 단일 스크롤
**문제**: 설정 페이지가 단일 스크롤 구조로 매우 길어 원하는 항목 찾기 어려움.  
구독 정보, 알림 설정, 계정 정보, 플랜 비교표, 팀 관리 등이 한 페이지에 모두 있음.  
**제안**: 상단에 앵커 네비게이션(#구독 #알림 #계정 #팀) 추가, 또는 탭 구조로 분리.

---

### P2-3. Trial 페이지 (`/trial`) — 업종 카테고리 검색 부재
**문제**: 59개 업종이 스크롤 목록으로 표시됨. 자신의 업종을 찾으려면 전체를 스크롤해야 함.  
**제안**: 업종명 검색 필터 입력창 추가, 또는 대분류 탭(음식·뷰티·교육·의료 등)으로 구조화.

---

### P2-4. 대시보드 모바일 (`/dashboard`) — 정보 밀도 과다
**문제**: 모바일에서 대시보드 콘텐츠가 매우 길어 소상공인이 중요 정보(오늘의 미션, 개선 방법)까지 스크롤해야 함.  
**제안**: 모바일에서 "오늘 할 일" 섹션을 더 상단으로 배치. 글로벌 AI 현황 등 상대적으로 덜 급한 정보는 접기(accordion) 처리.

---

### P2-5. 요금제 페이지 (`/pricing`) — 업종 선택 드롭다운 UX
**현재**: 업종 선택 드롭다운이 있으나 선택하지 않으면 "업종을 선택하면 맞춤 안내"가 표시됨.  
**문제**: 소상공인이 드롭다운을 건너뛰고 바로 요금제 카드를 보는 경우 채널 분기 안내를 놓침.  
**제안**: 기본값을 "음식점"으로 설정하거나, 업종 선택 유도 메시지를 더 눈에 띄게 표시.

---

### P2-6. 리뷰 답변 (`/review-inbox`) — "플레이스 플러스 AI 리뷰 답글" 업종 표기
**현재**: "음식점 전용" 태그가 있으나 비음식점 사용자에게도 표시됨.  
**문제**: 사진·영상 업종 사용자(홍스튜디오)에게 음식점 전용 기능이 그대로 보임.  
**제안**: 비대상 업종에게는 "내 업종은 현재 미지원" 안내 또는 섹션 숨김.

## P3 — 장기 개선 (백로그)

### P3-1. 홈페이지 모바일 — 전체 길이 단축
현재 모바일 홈페이지가 매우 길어 스크롤 피로도가 높음. 접기 구조나 핵심 CTA 중심으로 단축 검토.

### P3-2. 성장 리포트/창업 분석 (`/startup`) — 잠금 미리보기 강화
현재 잠금 상태에서 4개 기능 카드만 보이고 실제 결과 예시가 없음. 소상공인이 가치를 판단하기 어려움.  
예시 데이터(이미지)를 카드 내 포함하여 "이런 결과가 나옵니다" 표현 강화.

### P3-3. 경쟁사 관리 — 업종별 키워드 강조
경쟁사 카드에서 AI 브리핑 대상/비대상 여부를 아이콘으로 구분하면 소상공인이 경쟁 상황을 더 직관적으로 파악 가능.

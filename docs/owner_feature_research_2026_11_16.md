# 사장님이 필요로 하는 기능 외부 조사 (2026-11-16)

> 목적: `/tools`(사장님 계산기)·`/area`(우리 동네 상권) 다음에 추가할 기능 후보를 **근거가 있는 것만** 추려 추천한다.
> 원칙: 추정을 사실처럼 쓰지 않는다. 수치는 출처와 한계를 함께 적고, 확인하지 못한 것은 "미확인"으로 둔다.

## 0. 조사 방법과 한계 (오판·오탐 방지)

1. **검색 수요**: 네이버 검색광고 키워드도구 공식 API(`/keywordstool`)로 2026-11-16 서버에서 직접 조회한 **월간 검색량(PC+모바일 합계)**. 키워드는 공백을 뺀 형태로 조회했다.
   - 한계 ① 검색한 사람이 **사장님인지 직원인지** 구분되지 않는다(예: 퇴직금·시급·월급 계산기는 직원 비중이 클 가능성이 크다).
   - 한계 ② API는 10 미만을 0·10·20 등으로 뭉뚱그려 준다 → **0~20은 "거의 없음"이지 정확한 값이 아니다.**
   - 한계 ③ 첫 조회에서 일부(신용카드수수료·정책자금조회·노란우산공제)가 호출 한도 초과로 비었고, 잠시 뒤 다시 조회해 채웠다.
2. **유료/무료 대체재**: WebSearch 결과. 대부분 블로그·앱스토어 소개·기사라 **공식 요금·이용 통계는 확인하지 못했다**(아래 각 항목에 표시).
3. **"매일 쓰는 기능"의 객관적 이용 통계는 찾지 못했다.** 확인된 것은 앱 소개와 보도뿐이다(캐시노트 140만 사업장 보도, 토스 매장 장부 기능 소개).

## 4. 바로 할 수 있는 개선(새 기능 없이)

- 계산기 3종 페이지의 제목·소개에 실제 검색어 반영: **"배민·쿠팡이츠 수수료 계산기"**, **"마진율 계산기"**, **"주휴수당 계산기"**(현재 인건비 페이지가 주휴수당을 포함하지만 제목 맨 앞에 "직원 인건비"가 있음). 효과는 검색 반영 후 서치콘솔로 측정.

## 5. 다음에 확인해야 할 것 (선결)

1. 국세청 공식 신고·납부 일정 표(세금 달력용), 근로기준법·퇴직급여법 원문 또는 고용노동부 해설(5인 미만 적용), 소득세 세율표(국세청).
2. 중소기업중앙회 노란우산 공식 소득공제 한도 표(공제 한도 불일치 해소).
3. 공공데이터포털 "기업마당 지원사업 정보" 활용 신청·일일 호출 한도.
4. (선택) 사장님 대상 설문 또는 서비스 유입 데이터로 실제 사용 빈도 검증 — 지금까지는 **"매일 쓴다"는 주장을 뒷받침하는 객관 자료가 없다.**

## 6. 측정 재현

서버 `backend/`에서 `services/naver_searchad.get_searchad_client().get_keyword_volumes([...])`로 호출(공백 제거·5개씩 순차 호출). 호출이 몰리면 한도 초과로 일부가 비므로 키워드를 나눠 간격을 두고 조회할 것.

## A.1 반증 시도 — v2.0에서도 동일하게 유효한 경고

> v1.0 §1에서 반증한 핵심 결론을 v2.0에도 그대로 인계한다. 3단계 설계를 추진하기 전에 이 제약을 직시해야 한다.

**"3단계 신설이 주문을 늘릴 것인가?"에 대한 반증:**

- 현재 0건 원인이 **가격**인지 **발견 불가**인지 여전히 데이터가 없다.
- 대행 서비스 페이지는 로그인 후 대시보드에만 있다. 크몽 출시가 없으면 새 타겟 고객(AEOlab 비가입자)에게 노출 자체가 안 된다.
- 3단계 구조는 Kmong의 "심리적 앵커" 효과(STANDARD를 보면 DELUXE가 합리적으로 느껴지는 효과)를 노리는 것이다. 하지만 이 효과는 **한 페이지에서 3개 가격을 비교해볼 때만** 작동한다. 고객이 발견하지 못하면 앵커 효과가 없다.
- **살아남은 핵심 가설**: 1단계(저가) 진입 티어는 Kmong에 올렸을 때 실제 "AI SEO 진단" 검색 수요자에게 노출될 수 있다. 그 고객이 2~3단계로 업셀될 경로가 있다.

**스마트플레이스 등록 대행(3단계)의 제약 재확인:**
- `delivery_service_operation_manual_v1.0.md §4.1·§9`: 네이버 스마트플레이스 **부운영자 초대 UI 경로가 미검증 상태**. 아직 실 주문으로 테스트되지 않음.
- 1인 운영, 외주 불가. Playwright 세마포어 1개, RAM 4GB. 랜딩페이지·콘텐츠 10~20건 작성은 불가.
- 이 제약이 각 티어 산출물 설계에 직접 영향을 준다.

## A.2 크몽 벤치마크 구조 분석 — AEOlab 적용 가능성

| 항목 | Kmong gig785321 | AEOlab 적용 가능 여부 |
|------|-----------------|---------------------|
| STANDARD 29,000원 | 1일 진단보고서, 수정 0회 | ✅ 가능 — 실측 스캔 PDF 자동 생성 |
| DELUXE 890,000원 | 랜딩페이지+콘텐츠 10건, 7일 | ❌ 불가 — 랜딩페이지 제작 역량 없음(1인 운영) |
| PREMIUM 1,790,000원 | 5페이지 홈페이지+콘텐츠 20건 | ❌ 불가 — 동일 이유 |
| 타겟 | 병원·부동산·학원·법률 (B2B 고가) | AEOlab = 소상공인 (저가 결제 심리) |

**핵심 결론**: Kmong의 DELUXE/PREMIUM은 고가 B2B 모델이다. AEOlab은 소상공인 타겟이고 `agency_service_and_iboss_improvements_v1.0.md §1.2`가 명시한 "15만원 미만" 상한이 있다. 크몽의 **3단계 구조 틀**만 벤치마킹하되, 가격과 산출물은 AEOlab이 실제로 만들 수 있는 것으로 치환해야 한다.

### A.2-1 고객군 재확인 (사용자 지적, 2026-08-01 추가) — Kmong 고객은 "홈페이지+블로그" 보유 사업자로 한정

사용자 지적: "비교한 크몽 상품의 해당 고객은 홈페이지와 블로그로 한정되어 있음." DELUXE/PREMIUM의 산출물(랜딩페이지·5페이지 홈페이지·콘텐츠 10~20건)이 "제작"이 아니라 실은 **이미 홈페이지·블로그를 운영 중인 고객의 기존 채널을 AI 친화적으로 재구조화**하는 작업이라는 뜻으로 읽힌다. 즉 Kmong 타겟(병원·부동산·법률)은 자체 홈페이지+블로그가 이미 있는 사업자군이고, 그 위에 콘텐츠를 덧붙이는 상품이다.

**AEOlab 타겟과의 괴리**: AEOlab 핵심 타겟(소상공인 — restaurant/cafe/beauty 등)은 대다수가 **자체 홈페이지가 없고 스마트플레이스+블로그(네이버)가 주 채널**이다. 따라서 Kmong DELUXE/PREMIUM을 "불가"로 결론낸 게 이유는 맞지만(1인 운영 제작 역량 부족), 더 근본적으로는 **타겟 고객 자체가 다르므로 그대로 이식할 대상이 아니다.**

**그런데 AEOlab에는 이미 "블로그" 축을 다루는 기능이 구현돼 있다** — 홈페이지 대신 **블로그**가 AEOlab 고객군의 실질적 대응 채널이다(`backend/routers/blog.py`):
- `POST /api/blog/analyze` — 블로그 진단(글감·SEO·D.I.A. 품질 판정, `blog_analyzer.py`)
- `GET /api/blog/keyword-serp` — 키워드 SERP 노출 확인
- 블로그 소재(topic) 추천 — 검색량 연동(`docs/blog_analysis_v2_topic_volume.md`, SearchAd API 기준)

→ Kmong의 "콘텐츠 10~20건 제작"을 그대로 베끼지 말고, **AEOlab이 이미 가진 블로그 진단+소재추천 엔진을 상위 티어 산출물로 재포장**하는 것이 더 현실적인 벤치마킹 적용이다. 이 인사이트를 §A.4 산출물 설계에 반영한다.

## A.3 심리적 가격 설계 원칙 (v2.0 핵심 변경)

v1.0은 "최저시급 58,000원/h 충족"을 가격 정당화 근거로 사용했다. v2.0은 이 논리를 **버리고** 크몽의 심리적 가격 앵커 방식으로 전환한다.

### 소상공인 심리 가격 구간

| 구간 | 심리적 의미 | 예시 |
|------|-----------|------|
| 2~3만원대 | "한번 해볼까" 즉각 구매 (커피+스낵 수준) | 29,000원 |
| 7~8만원대 | "생각해봤는데 해볼게요" 의지 결제 | 79,000원 |
| 10~13만원대 | "투자한다"는 결심, 15만원 이하 안전선 | 119,000원 |
| 15만원 초과 | 소상공인 결제 저항 급증 구간 | **상한선** |

### 앵커링 효과 설계

```
1단계 29,000원  →  "저게 있으니 이게 싸 보인다"
                          ↓
2단계 79,000원  →  "이게 제일 합리적" (Decoy 효과, 가장 많이 선택)
                          ↓
3단계 119,000원 →  "다 포함이면 이거지" (전체 가치 앵커)
```

- 1단계 대비 2단계 추가 비용: +50,000원 (산출물은 크게 늘어남 → 2단계가 "합리적"으로 느껴짐)
- 2단계 대비 3단계 추가 비용: +40,000원 (스마트플레이스 등록 추가 → 소폭 추가)
- 3단계가 상대적으로 저렴하게 느껴지도록 2→3단계 gap을 1→2단계 gap보다 작게 설계

### Kmong 가격비율 vs AEOlab 가격비율

| 구분 | Kmong | AEOlab |
|------|-------|--------|
| 1단계 | 29,000원 (1x) | 29,000원 (1x) |
| 2단계 | 890,000원 (31x) | 79,000원 (2.7x) |
| 3단계 | 1,790,000원 (62x) | 119,000원 (4.1x) |

AEOlab의 비율이 Kmong보다 훨씬 촘촘하다. 이는 소상공인 예산 제약에 맞는 설계이며, 각 단계 간 "점프"가 크지 않아 업셀이 더 쉬울 수 있다.

## A.5 1회성 구조 확인

사용자 요청대로 이 3단계 상품은 **모두 1회성(one-time)**이다. 구독이 아님.

현행 `delivery_orders` 상태 머신이 그대로 적용된다:
```
received(접수) → paid(결제완료) → in_progress(진행중) → completed(완료)
                                    ↳ rework(재작업, 최대 1~2회)
```
- 결제: 토스페이먼츠 단건 결제 (빌링키 아님)
- 환불: 7일 내 자료 미제출 시 자동 환불 잡 (`delivery_auto_refund_job`) 기존 작동
- 재진단(3단계): `work_completed_at + 30일` 조건 자동 트리거 — 별도 주문이 아닌 완료 특전

코드 레벨에서 상태 머신, 결제 확인, 환불 로직 모두 패키지 타입에 무관하게 동작하므로 **신규 패키지 키 추가만으로 기존 인프라 전체 재활용 가능**. DB 마이그레이션 없음.

## 1. 반증 시도 먼저 — "저가 신설이 정말 주문을 늘릴까?"

### 1.1 "가격이 0건의 원인인가?"에 대한 반증

**가격 원인 가설**: 59,000원이 소상공인에게 너무 비싸서 주문이 없다.

**반증 시도 A — 발견(Discovery) 문제일 가능성**

- 현재 대행 서비스 페이지(`/delivery`)는 **로그인 후 대시보드 사이드바** 내에 위치. 비로그인 방문자는 랜딩의 `AgencyServiceSection`(하단, 스크롤 필요)에서만 접근 가능.
- AEOlab 구독자 = SaaS 도구를 직접 쓰려는 사람. 이들이 대행 서비스의 주 타겟인지 자체가 의문.
- 크몽 gig785321이 고객을 얻는 방식: 크몽 내부 검색("AI SEO", "GEO 마케팅")으로 유입. AEOlab은 이 유입 채널 자체가 없음.
- **결론**: 가격이 원인인지, 발견 불가가 원인인지 데이터가 없다. 가격을 낮춰도 아무도 보지 않으면 여전히 0건.

**반증 시도 B — 29,000원 티어 자체의 수요 증거가 얇다**

- 크몽 gig785321 STANDARD(29,000원)의 성과 근거: 20개 리뷰, 5.0점. 이는 "많이 팔린다"는 직접 증거로는 아직 소량(vs gig688406의 67,287건은 완전히 다른 상품 유형).
- gig785321의 실제 주수익은 DELUXE(890,000원)/PREMIUM(1,790,000원)일 가능성 있음. STANDARD 29,000원은 리드젠(깔때기 입구)이지 그 자체가 볼륨 상품이 아닐 수 있음.

**반증 시도 C — 크몽 진출의 운영 부담**

- 크몽은 리뷰 0건 초기 상태에서 유기적 노출이 매우 낮음. 첫 5~10건은 지인 의뢰 또는 광고 없이 어렵다.
- 수수료: 크몽은 거래액의 약 20% 공제(레벨별 상이, 신규는 약 20%). 29,000원 기준 공제액 약 5,800원, 실수취 23,200원.
- 크몽 메시지 SLA(응답 시간) 관리 등 추가 운영 부담 발생.

**반증 견딘 핵심 가설 (살아남은 것)**:

1. 크몽은 "AI SEO 진단 보고서"를 찾는 수요자가 실제로 있다 (gig785321 리뷰 20건 실측).
2. AEOlab의 실측 스캔(Gemini 100회+ChatGPT 100회+Naver+Google) 기반 보고서는 컨설턴트 주관적 진단보다 객관적 차별화 포인트가 명확하다.
3. 기존 01 가격 인하 없이 새 "진단 보고서 전용" 티어를 신설하면 최저시급 충족+저가 실현을 동시에 달성할 수 있다.

## 2. 신규 상품 핵심 발상 — "데이터 재포장"이 원가를 0에 가깝게 한다

AEOlab이 이미 가진 자산:

| 자산 | 테이블/엔드포인트 | 재활용 방식 |
|------|---------------|-----------|
| AI 스캔 결과 | `scan_results` | Gemini/ChatGPT 노출 횟수, AI 인용 여부 |
| AI 인용 실증 | `ai_citations` | 어떤 쿼리에서 언급됐는지 |
| 점수 시계열 | `score_history` | 최근 30일 추세 |
| 갭 분석 카드 | `gap_cards` | 개선 우선순위 |
| PDF 생성 인프라 | `/api/report/pdf/{biz_id}` | reportlab 기반, 이미 Pro+ 구현됨 |
| 스마트플레이스 체크 | `scan_results.website_check_result` | 완성도 항목 |

→ 이 데이터를 새로 만들 필요가 없다. **스캔 실행(자동) + PDF 생성(반자동) = 인건비 약 0.5h** 이하.

크몽 gig785321 STANDARD(29,000원)은 컨설턴트가 수동으로 작성하는 보고서다. 측정 기반 증거가 없다. AEOlab은 4개 AI 채널의 실측 데이터가 있어 동일 가격에 객관적 우위가 있다.

```
1. 주문 접수 알림 수신 (카카오 알림톡 자동)
2. 관리자: /admin/delivery에서 해당 주문 확인
3. 사업장 ID 복사 → /api/scan/full 실행 (또는 이미 스캔 있으면 기존 scan_results 재사용)
4. /api/report/pdf/{biz_id} 호출 → PDF 다운로드 (관리자 세션, Pro+ 권한)
5. PDF 검토 (5분): 이상값 없는지 확인
6. 관리자: /admin/delivery/{order_id}/materials로 PDF URL 업로드
7. /admin/delivery/{order_id}/status → "completed" 전환
8. 카카오 알림톡 완료 자동 발송
9. 보고서 하단 문구 확인: "AEOlab.co.kr에서 지속 추적 가능" 안내
총 소요시간: ~30분/건
```

### 8.1 성공 지표

### 8.2 가설 검증 기간

- **4주 차**: 크몽 gig 등록 후 노출/클릭 확인. 0클릭이면 gig 제목/설명 수정 우선.
- **8주 차**: 첫 5건 달성 여부. 미달 시 "가격이 아닌 발견 문제" 진단 → 크몽 gig 광고비 소액 집행 고려.
- **12주 차**: 월 10건 달성 여부. 달성 시 AEOlab 자체 채널 강화 + auto-report-generation 자동화 투자 검토.

### 8.3 실패 시 해석 기준

| 상황 | 해석 | 대응 |
|------|------|------|
| 크몽 클릭 0 | gig 노출 자체 안 됨 (리뷰 없음 초기) | 지인 2~3건 부탁, 리뷰 확보 후 재평가 |
| 클릭 있으나 주문 0 | 상품 설명/차별화 불명확 | gig 내용·포트폴리오 개선 |
| 주문 있으나 구독 전환 0 | 업셀 흐름 약함 | 완료 보고서에 구독 CTA 강화 |
| 0건 지속 (3개월) | 가격이 아닌 다른 근본 원인 | "발견" 문제로 진단, 랜딩 대행서비스 섹션 상향 이동 우선 |

## 9. 장기 자동화 로드맵 (구현 우선순위 낮음)

주문 월 10건 초과 시, 운영 시간(0.5h/건 × 10건 = 5h/월) 단축을 위해 자동화 고려:

```
[자동화 후보 — 구독자 BEP 5명+ 달성 후 검토]
- confirm_delivery_payment 훅: package_type='ai_diagnosis_report'인 경우
  → scan_results 최신 여부 확인 (7일 이내)
  → 오래됐으면 자동 scan_all() 실행
  → PDF 자동 생성 + materials_url 자동 저장
  → status 자동 'completed' 전환
  → 예상 추가 구현 시간: 4~6h
  → 달성 조건: 월 10건 초과 + BEP 5명 이후
```

현재는 반자동(운영자 검토 포함) 방식이 적절하다. 자동화는 가설 검증 후 볼륨이 생긴 시점에 투자한다.

## 11. 주의사항

- **최저시급 재역전 금지**: 00 상품 가격을 19,900원으로 내리면 0.5h 기준 39,800원/h이라 여전히 충족이나, 스캔이 예상보다 길어질 경우(1h) 시급이 19,900원/h로 최저임금과 근접해짐. 29,000원이 안전 마지노선.
- **크몽 계약 외부 유도 금지**: 크몽 정책상 gig 내에서 다른 플랫폼으로 직접 결제 유도는 금지. 완료 후 납품 PDF에 "aeolab.co.kr에서 지속 추적 가능"은 정보 제공으로 허용, 결제 링크 삽입은 금지.
- **PDF 생성 플랜 게이트**: 현재 `/api/report/pdf/{biz_id}`는 Pro+ 전용. 운영자 세션으로 호출 시 관리자 권한이 있으므로 기술적으로 가능하나, 자동화 시에는 이 엔드포인트를 delivery 서비스용으로 별도 권한 우회 처리 필요 (현재 반자동 SOP에서는 무관).
- **0건 진단 재확인**: 이 상품이 출시 후에도 3개월 후 0건이라면, 가격/상품 문제보다 "발견 문제"로 판단하고 크몽 gig 개선 또는 랜딩 AgencyServiceSection 위치 상향을 우선 검토한다. 가격을 더 내리는 것은 세 번째 수단 이하다.

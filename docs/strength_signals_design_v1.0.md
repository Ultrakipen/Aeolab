# 강점 신호 화면 설계 (2026-10-26, 설계만 — 구현 승인 전)

## 1. 목적과 원칙
- 목적: 점수·순위가 낮게 보일 때도 **측정으로 확인된 사실**을 먼저 보여 "저평가당했다"는 이탈 요인을 줄인다. 점수·성장 단계는 바꾸지 않는다.
- 이름 검색 1위는 강점 신호로 쓰지 않는다(정식 이름 전체로 검색하면 거의 모든 가게가 1위 — 17건 실측).
- 평가어("많다·우수") 금지. 사실 + 측정 시점 + 출처만. 입력값(사용자가 편집 가능, `business.py:361`)은 자동 수집이 확인된 경우에만 사용.
- 값이 0·NULL·측정 오류면 표시하지 않는다(0을 "없음"으로, 오류를 "미노출"로 오인 금지). 강점이 없으면 빈 상태 안내.
- 이미 있는 체험 화면 강점 목록(`TrialResultStep.tsx:183-270`)은 임계값이 느슨하다(블로그 1건·방문자 리뷰 1건도 강점) — 대시보드판 규칙 확정 후 통일 검토.

## 3. 시뮬레이션 (규칙 적용 시 사업장별 표시 결과)
- 어니언 성수: 방문자 리뷰 2,283건 · ChatGPT 추천 25/50회 · 카카오맵 등록. (AI 브리핑은 측정 오류라 표시 안 함, 경쟁 비교는 경쟁사 0곳이라 불가)
- 하라식당 본점: 방문자 리뷰 4,678건(평점 4.86) · 첫 화면 노출 키워드 3개. (AI 브리핑 True지만 측정 07-04로 오래돼 제외, 경쟁사 1곳이라 비교 불가)
- 홍뮤직스튜디오작곡교습소: 방문자 리뷰 45건 · AI 브리핑 노출(9-28) · 카카오맵 등록 · 첫 화면 키워드 2개 · 등록한 경쟁 가게 5곳 중 리뷰 2번째.
- 홍스튜디오: 방문자 리뷰 18건(평점 5.0) · 첫 화면 키워드 1개(웨딩본식, PC) · 등록한 경쟁 가게 3곳 중 리뷰 2번째.
- 대호흑돼지: 방문자 리뷰 80건만(나머지 신호 없음) — 얇다.
- 힐링하우스마사지(플레이스 ID 없음): 표시 항목 없음 → "스마트플레이스를 연결하면 확인된 강점이 표시됩니다".
→ 6곳 중 2곳(대호흑돼지·힐링하우스)은 거의 비어 있다. 빈 상태·얇은 상태 문구가 필수이며, "강점이 적다"는 인상을 주지 않게 "확인된 항목" 표현을 쓴다.

## 4. 오판·오탐·누락 점검 (설계 단계에서 이미 반영한 것)
- 오탐: 측정 오류(`error`)를 노출/미노출로 쓰지 않음, 입력 가능 값은 ID 자동수집 확인 후만, 평점 0.0 숨김, 경쟁 비교는 "내가 등록한" 집합임을 문구에 명시(사용자가 약한 경쟁사만 등록하면 부풀려질 수 있음 — 한계로 고지), 오래된 측정(30일 초과) 제외.
- 오판: ChatGPT "등장"은 측정 질문(지역·업종 추천 질문)에서의 등장 빈도이지 평판이 아님 — 질문 방식을 한 줄 설명. 구글 `mentioned`와 AI 개요 구분.
- 누락 가능성: 경쟁사를 등록하지 않은 신규 사용자는 상대 비교가 없음(경쟁사 추천 등록 유도는 별개 작업), 업종별로 쓸 수 있는 신호가 다름(숙박·학원 등은 미검증 — 8곳 표본 한계), 프랜차이즈 업종 특수 처리 미검토, 체험(비로그인) 화면과 규칙 불일치.
- 확인하지 못한 것: 사진 수·소식 최신성의 자동/입력 구분(스키마에 출처 컬럼 없음), 네이버 공식의 강점 해석 기준(외부 기준 없음 — 내부 사실 나열일 뿐 평가가 아니다).

## 5. 구현 구상 (승인 후)
- 백엔드: `GET /api/report/strengths/{biz_id}` — 위 규칙을 한 곳에서 계산해 `[{key, text, measured_at, source}]` 반환(AI 호출 0, 기존 테이블 조회만), 플랜 게이트 없이 로그인 소유자 한정. 규칙 단일 소스 + 단위 테스트(0·NULL·오류·오래됨·ID 없음·경쟁사 <3).
- 프론트: `StrengthSignalsCard` — PC는 히어로 카드 아래, 모바일은 접이식 기본 펼침. 각 항목에 측정일, 하단에 면책("측정 시점·기기·로그인 상태에 따라 달라질 수 있음").
- 점수·단계·알림 연동 없음.

## 6. 결정 필요
1. 신호 범위: 표의 "표시" 항목만으로 시작할지(권장), 보류 항목(소식·소개글·블로그·사진)을 출처 컬럼 추가 후 포함할지.
2. 경쟁 가게 대비 순위 문구("내가 등록한 경쟁 가게 N곳 중 K번째")를 사용할지.
3. 임계값 제안(ChatGPT 표본 ≥30, 측정 30일 이내, 경쟁사 ≥3곳)이 적절한지 — 모두 근거 약한 제안값.

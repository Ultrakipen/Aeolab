# 공개 문의 게시판 v1.0 (2026-10-13)

비로그인 방문자가 문의·건의·제휴를 남기는 게시판. **제목은 공개, 본문·답변은 작성 시 정한 비밀번호로만 열람.**
기존 로그인 전용 `/support`(1:1 티켓, 요금제 한도)는 그대로 유지 — 계정·결제 상담용.

## 구성
| 구분 | 경로 |
|---|---|
| DB | `public_posts` (RLS 활성·정책 없음 = 서비스 롤 전용) — SQL: `scripts/supabase_schema.sql` 말미 "공개 문의 게시판" 블록 (**SQL Editor 수동 실행**) |
| 백엔드 | `backend/routers/board.py` — 공개 `/api/board`, 관리자 `/admin/board` (감사 로그 대상 경로) |
| 프론트 | `/board`(목록)·`/board/new`·`/board/[id]` (`app/(public)/board/`), 관리자 `/admin/board` |
| 보존 파기 | `scheduler/jobs.py purge_old_board_posts` — 매일 03:40 KST, 1년 경과 글 삭제(공지 제외) |

## 진입점
푸터 "문의·건의"(`SiteFooter.tsx`) · 랜딩 PC 헤더 "문의"(lg+) · 도움말 CTA(`HelpContactCTA`) · 요금제 Biz 모달 하단 링크 · 모바일 랜딩 플로팅 시트(`HelpFAQFloat boardLink`)

## 보안·운영 규칙
- 비밀번호: `hashlib.scrypt`(솔트) 해시만 저장, 6~40자. 복구 불가(안내문 노출).
- 열람 무차별 대입 방어: 글별 연속 5회 실패 → 15분 잠금 + IP당 10분 30회.
- 작성 제한: IP당 시간당 5건·일 15건, 허니팟(`website`), 제목 길이 60자·본문 3000자.
- 제목에 전화번호·이메일·URL 패턴이면 거부(공개 제목 스팸/개인정보 방지). "제목도 비공개" 체크 시 목록에 "비밀글입니다."
- `/board/*` 는 `noindex, follow`.
- 답변 등록 시 작성자 이메일(선택 입력)로 알림, 신규 글은 `ADMIN_EMAILS`로 알림(Resend).
- 개인정보처리방침 §2·§3 항목 추가함(시행일은 미변경 — 공지 고지 필요 여부는 운영 판단).

## 알려진 한계
- 비밀번호 분실 시 작성자 본인 복구 수단 없음(운영자는 관리자 화면에서 열람·답변 가능).
- 레이트리밋 캐시는 프로세스 메모리(`--workers 1` 전제, 재시작 시 초기화).

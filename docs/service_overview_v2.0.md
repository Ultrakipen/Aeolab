## 1. 서비스 한 줄 정의

**AEOlab** — 소상공인이 네이버 AI 브리핑·AI탭·ChatGPT·Gemini에 더 잘 노출되도록 매주 자동 진단하고 즉시 실행 가능한 개선 방안을 제공하는 AI 검색 최적화(AEO) 플랫폼.

### 대상 사용자 3유형

| 사용자 | 핵심 니즈 | AEOlab 제공 가치 |
|--------|---------|---------------|
| 소상공인 | 광고비 없이 AI 검색 노출 확보 | 자동 진단 + 개선 가이드 + 콘텐츠 초안 |
| 다점포·대행사 | 여러 매장을 한 화면에서 관리 | 5사업장 매일 스캔 + 팀 계정 5명 |
| 예비 창업자 | 창업 전 이 지역 AI 경쟁 현황 | 창업 시장 분석 + 틈새 키워드 발굴 |

## 2. 핵심 모델 — 듀얼트랙 AI 가시성 점수 (v3.0)

```
통합 점수 = Track1(네이버) × 업종별 네이버 비율 + Track2(글로벌) × 업종별 글로벌 비율
성장 단계 기준 = Track1 단독 (업종 비율 차이로 인한 오판 방지)
```

### Track1 — 네이버 채널 점수 (5항목)

| 항목 | 가중치 | 측정 방법 |
|------|--------|---------|
| 키워드 커버리지 | 35% | 업종별 taxonomy 기준 리뷰·소개글 키워드 분포 |
| 리뷰 품질 | 25% | 리뷰 수·평점·다양성 |
| 스마트플레이스 완성도 | 15% | 소개글·소식·예약·사진·톡톡 메뉴 |
| 네이버 AI 브리핑 노출 | 15% | Playwright DOM 파싱 실측 |
| 카카오맵 완성도 | 10% | 카카오맵 프로필 완성도 |

### Track2 — 글로벌 AI 점수 (4항목)

| 항목 | 가중치 | 측정 방법 |
|------|--------|---------|
| AI 노출 빈도 | 40% | Gemini 50회 + ChatGPT 50회 언급 빈도 (Basic 기준) |
| 웹사이트 SEO | 30% | JSON-LD + Open Graph + 구조화 데이터 |
| 온라인 언급 | 20% | 네이버 블로그·뉴스·미디어 언급 수 |
| Google AI Overview | 10% | Playwright 실측 (Full 스캔만) |

### 업종별 네이버/글로벌 비율

| 업종 | 네이버 | 글로벌 |
|------|--------|--------|
| 음식점 | 70% | 30% |
| 카페·베이커리·바 | 65~70% | 30~35% |
| 숙박 | 70% | 30% |
| 미용·뷰티·피트니스 | 60~65% | 35~40% |
| 병원·약국 | 60% | 40% |
| 교육·학원 | 40% | 60% |
| 법률·세무·부동산 | 20% | 80% |
| 쇼핑·온라인몰 | 10% | 90% |
| 기타 | 60% | 40% (기본값) |

### 성장 단계 (Track1 점수 기준)

| 단계 | Track1 점수 |
|------|-----------|
| 시작 | 30점 미만 |
| 성장 중 | 30~54점 |

## 3. AI 스캐너 4종 (현재 운영 중)

> ⚠️ **v1.0 오류 수정**: Perplexity·Grok·Claude 스캐너·뤼튼은 이미 제거됨. 현재 4종만 운영.

| 스캐너 | 파일 | 방식 | Basic 자동 | Full(Pro+) |
|--------|------|------|-----------|-----------|
| Gemini 2.0 Flash | `gemini_scanner.py` | API | 50회 | 100회 |
| ChatGPT GPT-4o-mini | `chatgpt_scanner.py` | API | 50회 | 100회 |
| 네이버 AI 브리핑 | `naver_scanner.py` | Playwright | O | O |
| Google AI Overview | `google_scanner.py` | Playwright | X | O |

**스캔 모드:**
- **Trial** (무료 체험): Gemini 10회 + 네이버 (비로그인, IP당 일 3회)
- **Basic 자동** (주 1회): Gemini 50회 + ChatGPT 50회 + 네이버
- **Pro 자동** (주 3회): Gemini 100회 + ChatGPT 100회 + 네이버 + Google
- **Biz 자동** (매일): Gemini 100회 + ChatGPT 100회 + 네이버 + Google

**점수 산식:** Gemini 45점 + ChatGPT 45점 = 90점 → 100점 재배분. sample_size 기반 자동 처리.

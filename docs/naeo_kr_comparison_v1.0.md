# AEOlab 블로그 진단 vs naeo.kr — 실측 비교 (2026-07-18)

> naeo.kr 홈페이지·요금제 페이지를 Playwright로 직접 접속해 실측한 내용 + AEOlab 코드/라이브 데이터 직접 확인 결과. 오판·누락 방지를 위해 naeo.kr 쪽 주장은 FAQ 원문까지 펼쳐서 확인했고, AEOlab 쪽 주장은 전부 grep으로 코드 근거를 확인했다.

## 1. 서비스 성격 차이 — 전제부터 다르다

| | AEOlab | naeo.kr |
|---|---|---|
| 정체성 | 소상공인 AI 검색 노출 **종합 플랫폼** — 블로그는 5채널 중 1채널 | **블로그 전용** 단일 툴 (naeo.kr FAQ: "이미 블로그를 운영 중이고... 블로거에게 적합") |
| 타겟 | 사업장(가게)을 등록한 소상공인 | 블로거 개인(뷰티/IT테크/맛집 인플루언서 — 사업장 개념 없음) |
| 가격 스코프 | Basic 11,900원에 블로그+4채널AI스캔+경쟁사+스마트플레이스+가이드 전부 포함 | 블로그 진단 단독 19,900원(할인가, 정가 39,900원) |

**주의**: 가격만 단순 비교하면 AEOlab이 훨씬 싸 보이지만 스코프가 다르므로 이 표는 "무엇이 포함되는가"로 봐야 한다.

## 2. 채널 범위 — 검증된 가장 큰 차이

- **naeo.kr**: FAQ 원문("AI 브리핑이 뭔가요?") 확인 결과 — *"네이버에서 검색할 때 결과 상단에 AI가 요약해서 보여주는 답변... NAEO는 이 AI 브리핑에 내 글이 포함되었는지를 확인해줍니다."* 페이지 전체(홈·요금제)에 ChatGPT·Gemini·Google 언급 **0건** — **네이버 AI 브리핑 단일 채널**
- **AEOlab**: 블로그 진단 페이지의 "채널별 AI 인용 현황"이 네이버 AI 브리핑·ChatGPT·Gemini·Google AI Overview **4채널 실측 인용 횟수**를 각각 보여줌 (라이브 확인: `0/12회`, `0/3회`, `0/1회`, `0/3회`)

## 3. naeo.kr에 있고 AEOlab에 없는 것 — 코드로 재확인한 진짜 갭

| 기능 | naeo.kr 실측 내용 | AEOlab 확인 결과 |
|---|---|---|
| 키워드 검색량 **추이**(시계열) | 키워드 클릭 시 "검색량(4/22→5/13): 12,400→22,400 ▲80%", "문서수(경쟁 포화도) 추이"까지 표시 | `grep "volume_trend\|volume_history"` 0건 — `topic_suggestions_v2.monthly_volume`은 **스냅샷 1개 값**뿐, 추이 없음 |
| 키워드별 미니 SERP 뷰 | 키워드 클릭 시 연관키워드 5개+검색 상위 블로그 TOP3(실제 제목)+최근 뉴스 3개가 그 자리에서 펼쳐짐 | 없음 |
| 정량적 "포화도" 점수 | 0~1 float(예: 0.21, 0.52) | `topic_suggestions_v2.competition`은 `"low"/"medium"/"high"` **정성적** 값뿐 |
| AI 추천 **텍스트 vs 이미지** 유형 구분 | "AI 추천 12건 — 텍스트 17 / 이미지 6" | `ai_citations.mention_type` 값은 `recommendation/information/comparison/warning`(의미 유형)이지 텍스트/이미지 형식 구분 아님 — 이 구분 자체가 없음 |
| 포스트 **카테고리별** 분포·성과 | "맛집리뷰/카페/디저트"별 AI추천률·통합검색노출률 분리 | AEOlab은 업종 단위 진단이라 포스트 자체를 서브카테고리로 나눠 보여주지 않음 |
| 자동 스캔 빈도 | 베이직 플랜 "새 글 자동 분석"(매일 감지) | `daily_scan_all`은 **14일 이상 미분석 블로그만** 대상(주기가 더 긺) |
| 재분석 한도 | 무료 월5회(최대10 보유)/베이직 월50회(최대50 보유) | `plan_gate.py PLAN_LIMITS`: Basic **월 3회** — naeo.kr 무료 플랜보다도 적음 |
| 전사용자 랭킹+게이미피케이션 | "AI의 총애"·"키워드 사냥꾼"·"6월 왕" 등 배지, 전체/카테고리 순위 | 없음 — **단, 이미 알려진 항목**: `docs/blog_diagnosis_session_2026_07_18_handoff_v1.0.md §6-2`에서 "AEOlab 전체 사업장 7곳뿐이라 최소표본(3곳) 충족 불가로 지금 만들어도 못 채움"이라 의도적 보류 결정된 사항. 새 발견 아님. |
| 완전 무료 스탠드얼론 플랜 | 무료 플랜 존재(월5회) | AEOlab 블로그 진단은 로그인+사업장 등록 필수, 블로그 전용 무료 플랜 없음(전체 서비스 trial은 ChatGPT 5회뿐 별개) |

## 4. AEOlab에 있고 naeo.kr에 없는 것(확인된 것 위주)

| 기능 | AEOlab | naeo.kr |
|---|---|---|
| 멀티 AI 채널 실측 | 네이버+ChatGPT+Gemini+Google 4채널 | 네이버 단일(§2 확인) |
| LLM 기반 콘텐츠 진솔성 판정 | Claude Haiku로 "홍보 문구 위주" vs "진솔한 경험담" 실제 판정(오늘 라이브 확인: "AI 판단: 진솔한 경험담(결혼을 앞둔 신랑신부의...)") | 페이지 전체에 이 판정 개념 언급 없음(마케팅 페이지에 핵심 기능이면 반드시 노출했을 것 — 없을 가능성이 높으나 비공개 기능일 가능성은 단정 못 함) |
| 업종별 taxonomy 키워드 커버리지 | 59개 업종 화이트리스트+가중치 taxonomy 기반 확인/누락 키워드 분류 | 카테고리는 사용자가 자유 태그하는 방식으로 보임(맛집리뷰/카페 등), 업종별 표준 taxonomy 언급 없음 |
| 경쟁사 실제 매칭 기반 대비 | `comp_keywords`(경쟁사 관리 페이지 크롤링 재사용, 오늘 세션에서 토글 밖으로 승격) | "경쟁 콘텐츠 비교 분석"은 베이직 플랜에 있으나 세부 방식(내가 등록한 경쟁사 vs 자동 탐지)은 페이지에 명시 안 됨 — **불확실, 단정 회피** |
| 사업장 통합 진단 | 블로그가 스마트플레이스·리뷰·AI브리핑 게이팅과 하나의 사업장 점수로 통합 | 블로그 단독, 사업장/오프라인 매장 개념 없음 |
| 프랜차이즈 제외·플레이스형/정보형 AI브리핑 구분 | 네이버 공식 정책 반영(`score_engine.py`) | 이 세분화 언급 없음(단일 "AI 브리핑" 개념으로만 설명) |

## 5. 결론 — 무엇을 어떻게 봐야 하나

- **직접 경쟁 관계가 아니다**: naeo.kr은 "블로그 하나만 잘 키우고 싶은 개인 블로거"용 정밀 도구, AEOlab은 "가게를 AI 검색에 노출시키고 싶은 소상공인"용 종합 플랫폼 — 블로그는 AEOlab의 한 채널일 뿐.
- **naeo.kr이 실제로 더 깊게 파는 영역**: 키워드 단위 시계열 추이·SERP 미니뷰·포화도 정량화. 이건 "블로그 하나에 집중"하기 때문에 가능한 깊이이며, AEOlab이 지금 시급히 따라잡아야 할 항목은 아님(AEOlab의 핵심 축은 §1에서 이미 확정된 대로 ①내 블로그 현황 ②AI노출개선이지 "블로그 키워드 전략 툴"이 아님).
- **재분석 한도(Basic 월 3회)는 재검토 여지 있음**: naeo.kr 무료 플랜(월5회)보다도 적은 건 순수 사실 확인이며, 유료 Basic 사용자가 naeo.kr 무료 사용자보다 적게 재분석한다는 점은 사용자 경험상 불리할 수 있음 — 단, 이건 AI 호출 비용과 직결되는 정책 결정이라 **코드 변경이 아니라 사용자 판단이 필요한 사항**으로 제안만 하고 임의 변경하지 않음.
- **naeo.kr에 없는 것으로 확인된 AEOlab 강점(4채널 실측, LLM 진솔성 판정, 업종 taxonomy, 사업장 통합)이 실질적 차별화 지점** — 이미 §1에서 사용자가 확정한 "naeo.kr보다 더 전문적인 분석 + 내 블로그 현황 + AI 노출 여부" 목표에 부합.

- AEOlab: `grep "blog_monthly" backend/middleware/plan_gate.py`, `grep "volume_trend\|volume_history" backend/services/blog_analyzer.py`, `grep "mention_type" backend/` + `gemini_scanner.py` 프롬프트 원문 확인

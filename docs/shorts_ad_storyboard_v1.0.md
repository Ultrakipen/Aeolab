# AEOlab 숏츠 광고 스토리보드 v1.0

> 목표: 전환(체험신청)이 아닌 **인지도 — "이런 서비스가 있다"** 확산. 발견형(discovery) 포맷.
> 스펙: 25초 / 9:16 세로 / 자막 필수(무음 시청 대응) / 플랫폼: YouTube Shorts, Instagram Reels 우선 배포

## 1. 리서치 반영 원칙

- 첫 3초 이탈이 전체의 50~60% → 훅은 **정직하게 본편 내용을 반영**할 것 (과장 훅은 3초는 잡아도 완주율 급락)
- 자막은 **98px+ 굵은 글씨, 화면 하단 엄지 존(thumb-zone) 회피** 배치
- 구조: 0-3초 훅 → 3-15초 핵심가치 → 15-25초 시연/증거 → 마지막 5초 CTA (TikTok/Shorts 유료광고 벤치마크)
- 화면에 노출되는 점수·데이터는 **실제 체험 스캔 1회 실행 결과만 사용** — 더미 숫자·가짜 후기 금지 (CLAUDE.md 원칙)

## 4. 촬영/제작 준비물 (v1.1 — QA 계정 불필요로 정정)

- **실화면 캡처 대상** (전부 로그인 없이 접근 가능한 공개 페이지 — QA 계정 생성/삭제 절차 불필요)
  - `aeolab.co.kr/trial` 1단계 업종 선택 화면 (검색·가게찾기 단계까지는 진행하지 않아도 됨 — 완료 시 실제 ChatGPT API 5회가 호출되므로, 필요 이상 반복 실행은 지양)
  - `/showcase` 진단 리포트·채널별 상태·체크리스트 스크롤 (홍스튜디오 실데이터, 공개)
- **녹화 방법**: `playwright` 패키지가 이미 설치되어 있어 별도 도구 설치 없이 `page.video` 옵션으로 녹화 가능 — 스캔용 공유 세마포어(`PLAYWRIGHT_SEMAPHORE`)와는 무관한 **별도 1회성 스크립트**로 실행 (공개 페이지만 대상이므로 계정 관련 절차 없음)
- **모바일 실기기 목업**: 1번 샷은 실기기 촬영 또는 무료 목업 템플릿(Canva) 합성
- **편집 툴**: 컷 편집 + 자막은 Canva/VLLO 등 국내 무료 툴로 충분 (Remotion은 추후 데이터 기반 소재 자동 양산 단계에서 재검토)
- **⚠️ 음원(BGM) 저작권**: 유튜브/인스타 제공 저작권 프리 음원 라이브러리(YouTube 오디오 보관함, Instagram 사운드) 또는 상업적 이용 허가된 무료 음원만 사용 — 저작권 침해 시 플랫폼에서 광고 게재 차단·수익 창구 제한 가능
- **⚠️ 네이버/챗GPT 실제 로고·UI 노출 리스크(확인 필요, 미확정)**: 2번 샷의 AI 답변 화면에 네이버·OpenAI 공식 로고가 그대로 노출되면 제3자 광고 소재에서의 상표 사용 가이드라인에 저촉될 소지가 있음(단, 확정된 사실 아님 — 집행 전 각 사 브랜드 가이드라인 확인 또는 로고를 블러/제네릭 UI로 대체하는 안전한 대안 권장)

## 5. 배포 방식 전제 (누락 보완)

> 본 문서의 3초 유지율·훅 rate 등은 **유기적(organic) 게시 기준 알고리즘 지표**를 우선 적용. TikTok 33~55% hook rate·CTR 0.84% 등은 **유료광고 벤치마크**로, 실제 광고비 집행 여부(예산 미확정)에 따라 참고치로만 사용 — 무료 유기적 게시로 시작 후 반응이 좋으면 소액 부스팅 검토 권장.

## 6. 배포 후 확인할 지표

- 3초 유지율(intro retention) — 목표 70%+ (유기적 게시 기준)
- 완시청률(completion rate)
- 클릭·프로필 유입 → `/trial` 방문 전환 (단, 이번 캠페인 1차 목표는 인지도이므로 전환은 보조 지표)

> 이 문서는 매 대화창에서 동일한 기준으로 점검할 수 있도록 체계화된 기준서

## §0. 점검 원칙 (핵심)

1. **브라우저 직접 접속 원칙** — 모든 페이지는 `$B goto` 로 실제 접속 후 스크린샷·텍스트 추출. 코드만 보는 점검 금지.
2. **오판 방지 3단계** — 단정 전 ①근거 라인 확인 ②반증 시도 ③공식 출처 교차검증
3. **소상공인 관점 우선** — "네이버에 내 가게가 얼마나 잘 나오는가"가 핵심. 이 맥락에서 모든 항목 평가.
4. **CLAUDE.md 신뢰도** — CLAUDE.md는 스냅샷. 수치·기간·상태는 반드시 실제 코드+공식 출처로 검증 우선.
5. **AI 노출 기간 기준** — 아래 §1의 공식 조사 결과 기준. 기억/기존 문서만으로 표기 금지.

## §1. AI 도구별 노출 기간 공식 기준 (2026-06-26 조사)

| 채널 | 소요 기간 | 원리 | 공식 출처 |
|------|-----------|------|-----------|
| **네이버 AI 브리핑** | 2~4주 (추정) | 스마트플레이스 신호 기반 네이버 알고리즘 | 네이버 미공개 — 추정 표기 필수 |
| **네이버 AI탭** | 2~4주 (추정) | 블로그 UGC + 소개글 신호 기반 | 네이버 미공개 — 추정 표기 필수 |
| **Gemini** | 수 주~수개월 | Google 실시간 검색 grounding (GBP 인덱싱 연동) | Google 공식 미명시 — 합리적 추정 |
| **ChatGPT** | 수개월~1년 | 학습 데이터 기반 (knowledge cutoff 2024-06-01) | OpenAI 공식 docs 확인 ✅ |
| **Google AI Overview** | 수 주~수개월 | Google Search 실시간 인덱싱 연동 | Google 공식 미명시 |

> ⚠️ **Gemini 표기 주의**: Gemini는 실시간 Google 검색 grounding 경로(수 주~수개월)와 학습 데이터 경로(수개월~1년)가 분리됨.  
> 두 경로를 혼용하지 말 것. 소상공인에게는 "실시간 검색 연동 → 수 주~수개월"이 핵심 경로.

## §2. 페이지별 점검 기준

### 2.1 홈페이지 (`/`)
**점검 항목**:
- [ ] 헤드라인이 소상공인에게 네이버 중심 가치를 명확히 전달하는가
- [ ] 업종별 AI 브리핑 대상/비대상 구분이 정확한가 (ACTIVE: 음식점·카페·베이커리·바·숙박 / LIKELY: 미용실·네일·피부관리·반려동물·피트니스 등 11개 — "확대 예정" 별도 안내 톤 적용 여부 포함)
- [ ] 수치(+27.4% 등)에 면책 문구와 출처(네이버 공식)가 있는가
- [ ] AI 노출 기간 표기가 §1 기준에 맞는가
- [ ] 프랜차이즈 가맹점 제외 안내가 있는가
- [ ] 네이버 AI탭 출시 상태가 정확한가 (2026-06-25 정식 출시)
- [ ] Footer 서비스 설명이 실제 서비스 범위와 일치하는가
- [ ] 모바일 CTA 접근성 (스크롤 없이도 무료 진단 버튼 보이는가)
- [ ] PC 화면 가로폭 적절성 (1280px 기준)

### 2.2 Trial 페이지 (`/trial`)

## §3. 공통 점검 기준 (전 페이지 적용)

### 3.1 소상공인 이해도 (가장 중요)
- 전문 용어 → 인과관계 언어 전환 ("AI 노출 최적화" → "네이버에서 손님이 찾을 때 내 가게가 먼저 나옴")
- 지시만 하지 않고 **왜 해야 하는지** 설명 포함
- 개선 후 **기대 효과와 소요 기간** 명시

### 3.2 사실 정확성
- AI 노출 기간은 §1 기준, "추정" 배지 필수
- 수치 데이터에 출처 + 면책 문구 필수
- 네이버 AI탭 상태: "정식 출시" (베타 아님, 2026-06-25 이후)
- ChatGPT 면책: "학습 데이터 기반이며 실시간 웹 검색 결과와 다를 수 있습니다"

### 3.3 UI/UX
- **PC**: 본문 폭 과도하게 좁지 않음 (1280px 기준)
- **모바일**: 핵심 CTA/정보가 스크롤 없이 첫 화면에 노출
- **텍스트**: 최소 `text-sm` 이상, 소제목 충분히 명확
- **중복 콘텐츠**: 같은 정보가 한 페이지에 두 번 이상 나오지 않음
- **빈 상태**: "데이터 없음" 상태에서 다음 행동 안내 포함

### 3.4 네이버 우선 원칙
- 스캔 결과/대시보드에서 네이버 채널 정보가 최상단
- "스마트플레이스 개선 → 네이버 검색 상위노출" 인과관계 명시
- AI 브리핑·AI탭 구분 설명 (다른 경로임)

### 3.5 요금제 게이트
- 잠금(Lock) UI: 임의 숫자 더미 금지 → `--` 또는 텍스트
- 플랜 업그레이드 CTA가 명확하고 가격 즉시 확인 가능

## §5. 오판 방지 체크리스트

새로운 문제를 "P0/P1"으로 보고하기 전:
1. **근거 라인 확인**: 코드/화면에서 실제 표기된 위치 1줄 이상 직접 확인
2. **반증 시도**: "이게 맞다면 어디서 볼 수 있나?" 반례 탐색
3. **공식 출처**: 네이버·OpenAI·Google 공식 문서와 대조
4. **이전 문서 확인**: MEMORY.md/changelog에 이미 알려진 이슈인지 확인
5. **업종 분기 확인**: 현재 테스트 계정(hoozdev@gmail.com) 업종(사진·영상 = INACTIVE)의 특성이 일반 소상공인 대표 케이스가 아닐 수 있음

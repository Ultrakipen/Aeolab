| 축 | TalkB | AEOlab | 시사점 |

**겹치는 골격**: AI 인용 진단 → 점수화 → 월간 리포트 → 콘텐츠 개선. 기본 구조는 거의 동일.

### TalkB가 우리보다 잘하는 것
1. 프랜차이즈 본사 B2B 구조 (통합 대시보드 + 매장당 40% 단가 할감)
2. 신뢰자산(특허·9년·인증)으로 고가 정당화
3. 긴급성 카피 ("AI가 지금 사장님 옆집을 추천하고 있습니다")
4. 채널 진화 내러티브 (블로그 2010 → SNS 2014 → 유튜브 2017 → AI 검색 2026 "지금 자리 비어있음")

### 우리가 TalkB보다 잘하는 것
1. **네이버 AI 브리핑/AI탭** — 한국 소상공인 핵심 채널을 TalkB는 완전히 놓침
2. **₩9,900 진입장벽** — TalkB가 못 잡는 영세 소상공인 대중 시장
3. **셀프서비스 SaaS** — 대행 인건비 없이 확장 (BEP 20명)
4. **전업종** — 미용·숙박·병원·학원 등 비요식 무경쟁

## 4. 대응 방안

### A. 즉시 강조할 메시징 (네이버 해자)
TalkB의 최대 빈틈 = **네이버 부재**. 홈페이지·진단 결과에 대비 명시:
> "ChatGPT만 잡는 건 반쪽입니다. 한국 손님은 **네이버 AI 브리핑·AI탭**에서 먼저 가게를 찾습니다 — AEOlab은 네이버와 글로벌 AI를 **함께** 측정하는 유일한 서비스."

### B. TalkB가 버린 시장을 정면 공략
- ₩49,000/₩290,000 부담 → **₩9,900 + 셀프 진단**으로 "월 커피 두 잔 값" 포지셔닝
- 요식업만 → **미용·숙박·병원·학원** 등 비요식 업종에서 무경쟁

### C. 신뢰자산 격차 보완 (TalkB 강점 방어)
- 특허·9년은 단기 불가 → **실측 투명성**으로 대응 (측정 시점·기기 면책 + 실데이터만 노출, 이미 우리 원칙)
- 베타 후기 1~3개 확보(남은 작업) → 신뢰 공백 일부 보완

### D. 검토할 벤치마킹 (선택적)
- **"상황형 쿼리 라이브러리"** = TalkB 무기. 우리도 `keyword_taxonomy.build_ai_scan_queries()`(짧은 변형 3 + 자연어 변형 2)로 유사 기능 보유 → **마케팅 자산으로 전면화**하면 동등 대응
- **프랜차이즈 본사 B2B** — Enterprise(₩200,000)를 본사 통합 대시보드로 확장하는 건 **구독자 100명 이후 과제로 보류** (현 단계 BEP 우선)

## 5. 결론

TalkB와 AEOlab은 **"같은 카테고리, 다른 시장"**:
- **TalkB** = 요식업 프랜차이즈 대상 고가 대행 (₩49,000~₩290,000)
- **AEOlab** = 전업종 영세 소상공인 대상 저가 SaaS (₩9,900~)

직접 경쟁이 아니라 **시장 분할**이며, 우리의 결정적 우위는 **네이버 채널**.
단기 액션: "네이버 해자 강조 + ₩9,900 대중 시장 선점". 신뢰자산·B2B 본사는 후속 과제.

# naeo.kr MCP(생성+발행 자동화) vs AEOlab — 실측 비교 (2026-07-20)

> 선행 문서 `docs/naeo_kr_comparison_v1.0.md`(2026-07-18)는 naeo.kr 홈/요금제(진단 기능) 비교만 다뤘고 `/mcp` 페이지는 확인하지 않았음. 이 문서는 그 공백을 메운다. naeo.kr 쪽은 WebFetch로 `https://www.naeo.kr/mcp#usecases` 원문 확인, AEOlab 쪽은 grep으로 코드 근거 확인.

## 1. naeo.kr MCP가 하는 일 (원문 기반)

ChatGPT(Plus 이상 — Claude는 "준비 중", 이미지 전달 기능 부재로 아직 불완전) 대화창에서 MCP(Model Context Protocol)로 NAEO를 연결해 아래 5단계를 전부 대화로 처리:

1. **키워드 발굴**: "내 황금 키워드 보여주고, 글쓰기 좋은 것 3개만 추천해줘" → 검색량 높고 경쟁 빈 키워드 즉시 확인
2. **글쓰기+이미지**: "이 키워드로 내 블로그 말투에 맞춰 글 써줘" → AEO 처방(인용되기 좋은 구조·검색데이터 근거·사용자 말투) 반영해 ChatGPT가 이미지까지 생성
3. **저장**: 글은 자동으로 "발행 대기함"에 저장, 이미지도 대화 한마디로 추가 첨부
4. **네이버 에디터 자동 채움**: PC에서 NAEO 크롬 익스텐션 실행 시 대기함의 글+이미지가 네이버 에디터에 그대로 채워짐
5. **발행+추적**: 발행 버튼만 누르면 끝, 이후 순위·AI 브리핑 채택은 NAEO가 이어서 추적

특징: API 키 관리 불필요, 연결 3단계, NAEO 로그인 계정만 있으면 연결 가능(사용 가능 데이터 범위는 요금제 따름), 블로그 주소만 입력하면 무료 분석 시작.

## 3. 판단

- **카테고리 자체가 다르다**: naeo.kr MCP는 "생성(콘텐츠+이미지)+발행 자동화" 툴, AEOlab은 "진단(측정+분석+가이드)" 플랫폼. `naeo_kr_comparison_v1.0.md §5`에서 이미 확정한 "직접경쟁 아님" 결론과 정합적 — MCP는 그 결론을 뒤집는 근거가 아니라 같은 방향의 새 증거.
- **"더 깊다/얕다"가 아니라 "있다/없다" 갭**: 기존 비교(키워드추이·SERP미니뷰 등)는 정도 차이였지만, MCP 생성+발행 자동화는 AEOlab에 해당 카테고리 자체가 없음. 다만 이는 AEOlab이 의도적으로 선택하지 않은 영역(진단 플랫폼 정체성)이지 놓친 게 아님.
- **전략방향 원칙 적용**(`project_strategic_direction_2026_07_20`): 원칙3(기능보다 획득 우선, 사업장 7곳 규모에서 MCP서버+이미지생성+크롬익스텐션 유지비용 ROI 낮음) + 원칙4(naeo.kr 심화기능은 조건부 후순위)가 그대로 적용됨.
- **"뒤쳐지는 서비스"로 볼 근거는 약함** — 서비스 정체성이 다르고 AEOlab의 발행 후 추적 범위(4채널)는 오히려 naeo.kr(네이버 단일)보다 넓음. 단, 카테고리 자체 부재라는 점에서 원칙5(분기별 재확인 대상)에 이 MCP 트렌드를 추가하는 것을 권장 — ChatGPT/Claude MCP 생태계가 확산 중인 트렌드라 naeo.kr뿐 아니라 향후 다른 경쟁자도 채택할 가능성.

## 4. 결론

지금 시급히 따라잡을 항목은 아님. 사용자 피드백이 반복되거나(원칙4 조건), 사업장 수가 늘어 획득보다 리텐션/차별화가 우선순위가 될 때 재검토.

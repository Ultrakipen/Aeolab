## 2. 각 레이어 상세 정의

### ① 플레이스 AI 브리핑 (AEOlab에서 "네이버 AI 브리핑"으로 표기)

**정의**: 네이버 통합검색에서 특정 장소/업체를 검색했을 때, 검색 결과 플레이스 카드 상단에 AI가 리뷰·소개글·UGC를 분석해 요약 제공하는 기능.

**출시 이력**:
- 2025-03-27 정식 출시 (음식점·카페 중심 — 3월 24일 발표, 27일 서비스 시작)
- 2025-06-16 "플레이스 AI 브리핑" 강화 출시 (지도 통합형, 전자신문 확인)
- 2025-08-21 효과 공식 발표: 예약·주문 약 8% 증가, 체류시간 10.4%↑, 클릭률 27.4%↑, '더보기' 탭 137%↑
- 2026-04-01 숙박 업종 확대 (호텔·펜션·캠핑장·게스트하우스 약 1만5000개)

**커버리지**: 전체 검색결과 **20%** (2025-12 기준) → **40% 목표** (2026 연말, 네이버 공식)

**공식 효과 수치** (출처 구분 필수):
- **8% 증가**: 전체 대상 예약·주문 증가 (2025-08-21 공식 발표)
- **105% 증가**: 월 예약 5건 이하 소규모 업체 한정, 전년대비 (2026-04 출시 1년 성과 발표)
- 기존 예약 이력 없던 업체 일평균 **10건** 신규 예약 발생 (2026-04)
- 체류시간 10.4%↑ / 클릭률 27.4%↑ / '더보기' 탭 137%↑ (2025-08)

> ⚠️ UI에서 두 수치를 혼용하면 과장이 됨. 반드시 "전체 기준 8%" / "소규모 업체 한정 105%" 구분 표기.

**현재 적용 업종 (ACTIVE)**:
```
restaurant(음식점), cafe(카페), bakery(베이커리), bar(바), accommodation(숙박)
```

**확대 예정 업종 (LIKELY)**:
- 미용(beauty·nail 포함), 명소 등 **연내 두 자릿수 업종 목표** (네이버 최수연 대표 컨퍼런스콜 2026-02-06, 공식 발표)
- AEOlab LIKELY 코드 등록 (`score_engine.py:BRIEFING_LIKELY_CATEGORIES`, `userGroup.ts:LIKELY_CATEGORIES` 기준 — **12개**):
  ```
  beauty, nail, skincare, massage, spa, pet, fitness, yoga,
  pharmacy, dance, ballet, semi_permanent
  ```
  > ※ 이전 문서에 6개로 오기재됨 — 2026-05-28 정정. 코드가 단일 소스이며 이 목록이 기준.

**제외 대상**: 프랜차이즈 가맹점 (브랜드 카테고리) — 네이버 공식

**사업주 설정**: 스마트플레이스 → AI 정보 탭 → "AI 브리핑 노출하기" ON/OFF (변경 후 약 1일 내 반영)

**AEOlab 측정 방법**: `naver_scanner.py` Playwright → `in_briefing=True/False`, `ad_only`, `excerpt`

### ② AI탭 (AEOlab에서 "네이버 AI탭"으로 표기)

**정의**: 네이버 통합검색 결과 내 별도 "AI" 탭. 대화형 AI 검색 서비스로, 쇼핑·장소 예약까지 한 화면에서 처리.

**출시**: 2026-04-27 베타 (네이버플러스 구독자 우선) → **2026년 6월 전체 사용자 정식 출시 예정**
> ⚠️ 2026-05-30 재검증: 뉴스핌 2026-05-28 "AI탭 내달 출시" 보도 기준. 5월 29일 이전 문서에 "2026-05-29 정식 출시"로 오기재됐으나 실제는 6월 예정.

**베타 성과**: 베타 1개월 누적 사용자 **300만명** 돌파, 재사용률 36%, 긍정 피드백 71% (2026-05-29 기준)

**구조**:
- **쇼핑 에이전트**: 제품 추천 → 구매 링크 직접 연결
- **플레이스 에이전트**: 음식점·장소 추천 → 예약 버튼 직접 표시 (플레이스 방문자 리뷰·블로그 후기 약 100개 출처 기반)

**업종 제한**: **공식 제한 없음** — 장소 기반 모든 업종이 플레이스 에이전트를 통해 노출 가능. 현재 음식점·카페·쇼핑 등 플레이스 기반 결과가 주로 노출됨.

**접근 경로**:
- PC/모바일 메인 검색창
- 검색결과 상단 "AI" 탭
- AI 브리핑 하단 링크
- 쇼핑·플레이스 통합검색 결과 내

**AEOlab 측정**: P2 (미구현). 현재 `AiTabPreviewCard`는 스마트플레이스 등록 데이터 기반 **시뮬레이션**이며, 실측 데이터가 아님.

> **⚠️ P2 트리거 조건**: 2026년 6월 전체 출시 후 SSH로 비로그인 AI탭 노출 확인 → P2 실행. `docs/remaining_tasks_v1.0.md` P2 트리거 확인 명령 참조.

**플레이스 AI 브리핑과의 관계**:
- AI 브리핑: 검색결과 플레이스 카드 내 요약박스 (수동 설정, 업종 제한 있음)
- AI탭: 별도 대화형 탭 (업종 제한 없음, 플레이스 데이터 활용하지만 별개 경로)
- 두 서비스는 공통된 스마트플레이스 데이터를 활용하지만 **노출 경로·조건이 다름**

### ③ AI 정보 탭 (AEOlab에서 "AI 정보 탭"으로 표기)

**정의**: 스마트플레이스 관리자 페이지 내 설정 메뉴. AI 브리핑 노출 여부를 사업주가 직접 ON/OFF 하는 도구.

**경로**: smartplace.naver.com → 내 업체정보 → AI 정보 탭 → "AI 브리핑 노출하기" 토글

**주의**: 이 탭이 안 보이면 = 해당 업종 AI 브리핑 비대상 또는 조건 미충족

| "직접 인용" | 단정 표현 금지 (기존 CLAUDE.md 원칙) | "인용 가능성" |

## 7. 에이전트N — 네이버 통합 AI 에이전트 로드맵

**정의**: 네이버 서비스 전반의 데이터·기술 인프라를 통합한 AI 에이전트 개념. 단순 답변이 아닌 실행 옵션(예약·구매·결제)을 제안하는 방식.

**공개**: **2025-11-06 DAN 25 컨퍼런스에서 이미 공개됨** (2026년 출시가 아님)

**로드맵 (공식 발표 기준)**:
```
2026 Q1  쇼핑 에이전트 → 네이버플러스 스토어 적용
2026 Q2  AI탭 출시 (4/27 베타 → 5/29 전체 사용자 정식 출시) ✅ 완료
이후     금융·플레이스 에이전트 단계적 확장
```

> ⚠️ 이전 문서에 "Agent N 2026년 여름 출시 예정" 오기재 — 에이전트N은 2025년 이미 공개됨. AI탭이 Q2 구현물.

**명소(attraction) 업종**: 네이버 공식 발표에서 "미용·명소 등 연내 확대 예정" 언급됨. 그러나 AEOlab 업종 화이트리스트 25개에 "명소/attraction" 없음 → 현재 코드 이슈 없음. 추후 업종 추가 시 LIKELY 분류 검토.

**AEOlab 관련성**: AI탭 최적화(소개글·사진·리뷰·예약 연동)가 에이전트N 전반에도 유효. P2 AI탭 Playwright 실측 구현 후 플레이스 에이전트 노출 기준 별도 검토.

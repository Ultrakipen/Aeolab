# 알림톡 승인 본문 (콘솔 캡처 기준, 2026-10-31 촬영 · 2026-11-01 정리)

사용자가 비즈센터 콘솔에서 찍은 24장(`바탕화면/새 폴더`, `새 폴더 (2)`)을 읽어 정리했다. **이 문서가 승인 본문의 기준**이며, 7월 기록 문서(`kakao_notify_template_revision_v1.0.md` 등)보다 우선한다.
캡처에서 본문 아래쪽이 잘린 템플릿은 표시했다(안내 문장 끝부분 미확인). `AEOLAB_ACTION_01`은 캡처에 없어 7월 기록(`kakao_alimtalk_submission_final_v1.0.md` §6)을 따른다.
재현 도구: `cd backend && python scripts/render_alimtalk_messages.py` — 실제 코드가 만드는 변수 값을 이 본문에 끼워 사용자가 받는 문장을 출력한다(네트워크·DB 미사용).

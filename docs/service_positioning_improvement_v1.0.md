# 서비스 포지셔닝 개선 계획 v1.0

> 작성일: 2026-05-26
> 배경: 사용자 기대치 오해 리스크 분석 → AI 노출 개선 소요 기간 재검증 → 포지셔닝 재설계
> 상태: 구현 대기

---

## 1. 문제 정의

### 현재 암묵적 약속 vs 현실

| 항목 | 현재 서비스가 암시하는 것 | 실제 |
|------|------------------------|------|
| 가치 제안 | "AI 노출을 높여드립니다" | 진단·가이드 제공. 실행은 사용자 몫 |
| ChatGPT 점수 | 개선 가능한 지표처럼 표시 | 학습 데이터 기반 — 단기 개선 불가 |
| 개선 기간 | 명시 없음 → 단기 기대 유발 | 공식 기간 없음. 수주~수개월 이상 |
| 점수 상승 | 스캔 후 즉시 반영 가능 암시 | 사용자가 수주~수개월 실행 후 반영 |

### 허위광고 리스크 판정

- **허위광고 수준 아님** — 서비스 자체(진단·가이드)는 사실
- **과장광고 리스크 존재** — "노출 개선" 클레임이 서비스 직접 효과처럼 읽힘
- **기대치 불일치 리스크** — 장기 소요 안내 없음 → 단기 이탈 원인

### 소요 기간 재검증 결과 (2026-05-26 웹 조사)

| 출처 | 내용 | 신뢰도 |
|------|------|--------|
| 네이버 공식 | AI 정보 탭 설정 변경 → **1일 반영** 유일한 공식 기간 | ✅ |
| 리드젠랩 가이드 | "구체적 소요 기간 없음" 직접 확인 | ✅ |
| 아이보스 2026 | "지속적 관리 강조", 기간 미명시 | ✅ |
| 마케팅 업체 | "2주 만에 1위" 등 주장 | ❌ 과장 |
| 개업 90일 골든타임 | 신규 매장 한정 | ⚠️ 부분 적용 |

**결론: 네이버는 AI 브리핑 개선 소요 기간을 공식 발표하지 않는다.**

## 2. 포지셔닝 재설계

### 핵심 전환: "결과 약속" → "인텔리전스 플랫폼"

```
Before: "AI 검색 노출을 높여드립니다"
        (결과 약속 → 장기 소요 = 신뢰 붕괴)

After:  "AI 검색에서 내 가게의 위치를
         경쟁사와 비교해 정확히 알 수 있습니다"
        (진단 약속 → Day 1에 즉시 충족)
```

### 가치 제공 타임라인 재설계

```
Day 1  [즉시] 스캔 결과 = "나는 42점, 1위 경쟁사는 78점"
              → 충격적 갭 인식 = 가입 정당화
              → "내가 이렇게 뒤처져 있었구나" = 즉각적 가치

Week 1 [단기] 즉시 실행 항목 완료 체크리스트
              → 소개글·사진·설정 완료 → 체크 만족감

Month 1~3 [중기] 매월 스캔 점수 변화 추적
                 → "지난달보다 8점 올랐다" = 진전 가시화

3개월+ [장기] 실제 AI 노출 변화 (최종 결과)
```

### 성공 사례 벤치마크

| 서비스 | 최종 결과 | 즉시 제공 가치 | 구독 유지 요인 |
|--------|---------|-------------|-------------|
| Ahrefs | 검색 1위 | 지금 내 순위·경쟁사 분석 | 매주 변화 추적 |
| 헬스 앱 | 체중 감량 | 오늘 내 상태 측정 | 일일 기록 |
| 회계 SaaS | 매출 증가 | 지금 재무 현황 | 월별 리포트 |

## 3. 구체적 수정 항목

### A. 랜딩 페이지 히어로 문구

| 위치 | 수정 전 | 수정 후 |
|------|--------|--------|
| 헤더 배지 | "AI 노출 관리" | "AI 노출 진단·추적" |
| 메인 헤드라인 | 노출 개선 약속 | 경쟁사 대비 현황 파악 강조 |
| 서브 카피 | — | "AI 노출은 즉시 바뀌지 않습니다. 대신 지금 정확히 어디에 있는지 알 수 있습니다" |

### B. 대시보드 — 사업장 미등록 상태

| 수정 전 | 수정 후 |
|--------|--------|
| "AI 브리핑 노출 개선 가이드" | "AI 브리핑 노출 현황 진단·개선 방향 제시" |

### C. 대시보드 — 기대치 안내 배너 신규 추가

```
위치: DashboardScoreZone 상단 또는 최초 스캔 후 1회 표시
내용: "AI 노출 개선은 즉각적이지 않습니다.
       설정 변경은 1일, 콘텐츠 최적화 효과는
       수주~수개월 후 나타납니다.
       AEOlab은 그 과정을 매주 추적합니다."
조건: 첫 스캔 완료 후 1회만 표시 (로컬스토리지 플래그)
```

### D. ChatGPT 카드 면책 강화

```
현재: "측정 원리 차이: ChatGPT(gpt-4.1-mini)는 학습 데이터(컷오프 2024.06) 기반"
      → 하단 작은 글씨로 묻혀 있음

수정: 카드 상단에 별도 배지로 표시
      [진단 전용] ChatGPT 점수는 학습 데이터 기반이며
                  단기 최적화가 불가능합니다. 현황 파악 목적입니다.
```

### E. 가이드 항목 — 행동 유형 배지 (기간 수치 대신)

```
[즉시 실행]  → 스마트플레이스 AI 정보 탭 설정 ON (1일 반영 — 네이버 공식)
[즉시 실행]  → 스마트플레이스 사진·소개글·소식 등록
[꾸준한 실행] → 네이버 블로그 정기 작성, 리뷰 답변 축적
[단기 불가]  → ChatGPT 점수 향상 (학습 데이터 기반)
```

## 1. 서비스 컨셉 (현재 "AEOlab")

**핵심 가치**: 경쟁 사업체를 분석해 업종별 평가 기준을 만들고, 그 기준으로 내 사업장을 진단하여 AI 검색(네이버 AI 브리핑·AI탭, ChatGPT, Gemini, Google AI Overview) 노출 개선 방안을 제공하는 한국 소상공인 대상 SaaS.

**3대 사용자**: 소상공인(사업장 성장) / 시장 조사자(업종 분석) / 예비 창업자(시장 조사)

**차별점**:
- 네이버 AI 브리핑·스마트플레이스 딥 통합 (국내 특화, 해외 AEO/GEO 툴에는 없음)
- 듀얼트랙 점수 모델(Track1 네이버 + Track2 글로벌 AI, 업종별 가중치 차등)
- 진단에 그치지 않고 실행 가이드·콘텐츠 자동생성까지 제공
- 이미 유료 구독 운영 중(BEP 20명 목표, 무명 서비스 단계)

**요금제**: Basic 11,900원 / 창업패키지 12,900원 / Pro 23,900원 / Biz 49,900원 / Enterprise 200,000원

## 2. 리네이밍 검토가 시작된 계기

2026-09-07 외부 관점 진단 아티팩트(사업가·마케터·기획자·네이미스트·트렌드 애널리스트 5개 렌즈, 내부 문서 미참조 독립 조사)에서:

- **"AEO"가 한국에서 이미 관세청 공식 제도명**(수출입안전관리우수업체, Authorized Economic Operator)으로 통용 중, 한국AEO진흥협회(aeo.or.kr) 도메인까지 존재
- **동일 문자열 "aeolab"을 이미 다른 회사(제이드필러)가 브랜드로 사용 중**(`aeolab.oopy.io`)
- 리브랜딩 자체는 "비용이 큰 결정이라 결론 내리지 않는다"며 우선순위 5개에는 미포함

이후 대화에서 자체 재조사로 추가 확인:
- **"AEO" 검색 시 상위 결과 전부 관세청 제도 관련** — SEO 유기적 유입 기대 불가 확정
- **"aeolab" 검색 시 실제로 제이드필러가 인덱싱되어 노출** — 이론이 아닌 실측 확인된 리스크
- 대형 리브랜딩 실패 사례(트로피카나·Gap 등)는 **이미 브랜드 자산이 큰 기업**의 사례라 BEP 20명도 미달한 AEOlab에는 적용 안 됨 → 오히려 "지금이 가장 비용이 적게 드는 시점"으로 결론

**결론: 유지보다 변경이 타당하다고 판단, 리네이밍 진행 결정.**

## 5. 핵심 사건 — 직접 경쟁사 "보임(BOIM)" 발견 (2026-09-07)

사용자가 실제 서비스 `https://boim.app/`를 제시하며 발견됨. 조사 결과:

| 항목 | 내용 |

| 슬로건 | "ChatGPT가 당신의 가게를 아직 모릅니다" |
| 기능 | 측정(AI 노출도 추적)→분석(인용 출처 파악)→생성(AI친화적 콘텐츠)→발행(자동 발행) |
| 타겟 | 소상공인, 식당·카페 로컬비즈니스 |
| 측정방식 | 매주 실제 구매질문 40개를 ChatGPT·Perplexity에 반복 입력해 SoAV(AI답변 점유율) 측정, 경쟁사 비교 |
| 출시 | 2026년 3분기 예정, 현재 베타 사전신청 |
| 발견 경로 | Disquiet(국내 인디 메이커 커뮤니티) — 1인/소규모 팀으로 추정 |

- 듀얼트랙 점수 모델(업종별 네이버/글로벌 가중치 차등)
- 이미 유료 구독 운영 중(boim.app은 사전신청 단계)

**"보임" 단어 자체의 포화 상태**(app store·기업 검색으로 추가 확인):

### 7.1 방법론 전환 — Lexicon 네이밍 프레임워크 적용 (라운드15)

사용자가 브랜드 네이밍 전문회사 Lexicon(스위퍼·블랙베리·펜티엄 작명)의 방법론 글을 공유. 핵심: "안전한 이름(인비저블 존)을 피하고 텐션 존을 추구하라" + "혜택 사다리(기능→기능적혜택→감정적혜택→궁극적혜택)를 최상위까지 올려라". 이를 적용해 "AI가 검색에 나타난다"는 기능적 혜택 대신 **"시대에 뒤처지지 않고 살아남는다"**는 궁극적 혜택 층위에서 "쫄지마"·"기죽지마" 등을 도출 — 이 방법론 자체는 유효했으나 사용자가 이 방향을 최종 채택하지는 않음.

### 7.2 결정적 재평가 — "AEOlab 자신을 같은 기준으로 평가"

200개 후보가 계속 기준 미달로 탈락하자, 사용자 요청으로 **"AEOlab" 자신에게 동일 기준(①실제 브랜드 충돌 없음 ②포괄적이지 않음)을 적용**:
- AEOlab은 이 기준으로 보면 **200개 탈락 후보보다 더 심하게 기준 미달**(관세청 정부기관 용어 + 실제 인접업계 회사 충돌)
- 그런데도 AEOlab은 **실제로 운영되고 구독자가 있는 살아있는 서비스**
- **결론**: "검색하면 뭔가 걸린다"는 것 자체는 사업에 치명적이지 않다. 진짜 위험한 건 **①같은 업종 직접 경쟁사가 동일 이름 사용 ②타겟이 뜻을 이해 못함** 이 두 가지뿐. 무관 업종과의 우연한 겹침은 실무적으로 허용 가능한 수준.
- 이 재평가 이후 "완화된 기준"을 재적용해 알봄·까치·열매·알온이 부활했으나, 사용자가 최종적으로 "알봄" 1건만 채택하고 나머지는 개별 사유로 재기각(까치·마온 등은 여전히 엄격 기준 적용해 제외).

## 9. 재발 방지 메모 (전체 세션 종합)

- **"grep 0건" ≠ "충돌 없음"** — 앱스토어·Disquiet 같은 메이커 커뮤니티, 실제 법인등록 검색, 투자정보 플랫폼(넥스트유니콘 등)까지 확인해야 진짜 검증. "보임" 사고 때 일반 웹검색만으로 6개 이상의 기존 사용처를 놓쳤음.
- **"완벽한 0건 충돌"은 비현실적 기준일 수 있다** — AEOlab 자신도 이 기준을 통과 못 함에도 실제 운영 중. 진짜 판단 기준은 "①같은 업종 직접 경쟁사 유무 ②타겟의 이해도" 두 가지로 좁혀야 탐색이 수렴한다(200개 시도 끝에 도달한 결론).
- **동사 활용형/구어체 조어(찾아줌·보여줌·나오나 등)는 구조적으로 위험** — 문장 속에서 자연발생하는 표현이라 이미 여러 무관 업종에서 "OO+동사" 패턴으로 반복 사용됨. 명사형이 상대적으로 안전.
- **후보 탐색 시 매 라운드 "왜 이전 라운드가 안 맞았는지" 먼저 확인 후 다음 라운드 진행** — 막연히 새 단어를 계속 추측하기보다, 사용자에게 구체적 톤·기준을 먼저 확인하는 것이 효율적.
- 사업자상호(케이엔디 커뮤니티)는 리네이밍과 무관 — 절대 변경 대상 아님.
- 가입자 0명(개발 중) 상태라는 사실이 뒤늦게 확인됨 — 이 정보가 리브랜딩 리스크 계산에 처음부터 반영됐어야 함(과도기 대응 등 불필요한 논의가 있었음).

### 10.3 결론 — 리네이밍 긴급성 소멸, "보류"로 전환

- §7.2에서 확정한 "진짜 위험한 건 ①동일업종 직접경쟁사가 동일이름 사용 ②타겟이 뜻을 이해 못함, 이 둘뿐"이라는 자체 기준에 비춰보면, 근거②(제이드필러)는 **비활성 경쟁사**라 ①을 충족하지 못함. 근거①(관세청)도 사용자 판단으로 제외.
- 남는 리스크는 "완벽한 0건 충돌은 아니다"는 약한 수준뿐 — §9에서 이미 "AEOlab 자신도 이 기준을 통과 못 해도 실제 운영 중"이라 결론 낸 것과 같은 층위.
- **잔존 불확실성**: 제이드필러 도메인이 죽었다고 상표/상호 자체가 소멸했다는 보장은 없음(폐업신고 여부 미확인) — 나중에 재등장·제3자 재등록 가능성은 남음. 단 "지금 당장 강행해야 한다"는 긴급성은 없음.
- **§8의 "알봄" 최종 결정·도메인 구매 체크리스트는 폐기하지 않고 보류 상태로 유지** — 재개 여부는 추후 판단.

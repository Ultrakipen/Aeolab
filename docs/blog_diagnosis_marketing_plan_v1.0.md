# 블로그 진단 페이지 — 사용자 가입 유도 마케팅 계획 v1.0 (2026-07-18)

> 2026-07-18 세션(naeo.kr 경쟁분석·4개 기능 구현·재검증)의 자연스러운 후속. 마케팅 실행 전 오판/누락 검증을 거쳐 작성. 코드 변경 없음 — 순수 전략 문서.

## 0. 오판/누락 검증 이력 (이 문서를 믿기 전에 볼 것)

작성 과정에서 이전 턴에 구두로 언급했던 내용을 코드로 재검증한 결과 **1건의 오류를 발견·정정**했다:

| 이전 발언 | 재검증 결과 |
|---|---|
| ~~"growth-funnel 관리자 페이지에서 확인"~~ | ❌ **오류로 확정.** `grep` 결과 `backend/routers/admin.py:555` `GET /admin/growth-funnel` API는 실재하나, 이를 렌더링하는 프론트엔드 페이지는 **어디에도 없음**(frontend 전체 검색 0건). 즉 지금은 API를 Swagger/curl로 직접 호출해야만 확인 가능 — "페이지"라는 표현 자체가 틀렸다. |

## 1. 핵심 전제 — 이 계획이 풀어야 하는 문제

2026-07-18 세션에서 확인한 사실: AEOlab 블로그 진단 페이지는 **기능 설계상 naeo.kr 대비 대부분을 보완·일부 초과**했으나, 랭킹·업종평균 같은 네트워크효과 의존 기능은 **현재 사업장 수 부족으로 실제 가치를 못 내는 상태**(랭킹 실측: `2곳 중 2위`). 즉 이 마케팅 계획의 목표는 "부족한 기능을 마케팅으로 감추는 것"이 아니라 **"이미 완성된 차별화 기능으로 초기 고객을 모아, 그 결과로 네트워크효과 기능이 자연히 채워지게 만드는 것"**이다.

## 2. 원칙 — 무엇을 앞세우고 무엇을 숨길 것인가

| 구분 | 항목 | 근거 |
|---|---|---|
| ✅ 전면 배치 | 4채널 실측(네이버·ChatGPT·Gemini·Google) | naeo(네이버 단일, `docs/naeo_kr_comparison_v1.0.md` §2 확인)와 정면 차별화, N=1이어도 완전한 가치 |
| ✅ 전면 배치 | LLM 콘텐츠 진솔성 판정(Claude Haiku) | naeo에 이 기능 없음(확인됨), N 무관하게 즉시 가치 |
| ✅ 전면 배치 | 스마트플레이스+블로그+경쟁사 통합 진단 | naeo는 블로그 단독 툴 — "가게 전체"를 보는 AEOlab만의 스코프 |
| ❌ 전면 배치 금지 | 전체 랭킹, 업종 평균 대비 | 실측 `2곳 중 2위` — 지금 노출하면 "안 쓰는 서비스"로 오인. UI는 이미 이 원칙대로 percentile 숨김 설계됨(`show_tier: false`), 마케팅 카피도 동일 원칙 적용 |

## 3. 활용 가능한 기존 인프라 (신규 개발 불필요)

| 자산 | 현재 상태 | 활용 방법 |
|---|---|---|
| 무료체험(ChatGPT 5회, 비로그인) | 구현됨, 실사용 0명 추정(재확인 필요) | 진입 장벽 최소 채널 — 랜딩·광고 CTA를 전부 이쪽으로 |
| 첫 달 50% 할인(11,900→5,950원) | 구현·검증 완료(`prices.py`) | 트라이얼 직후 전환 유도 카피에 명시적으로 노출 |
| 연간 구독 17% 할인 | 구현됨(`YEARLY_PRICE_MAP`) | 재구독 의사 있는 고객 대상 2차 오퍼(초기 신규유입용 아님) |
| 카카오 알림톡 5종 | 구현·승인 완료 | 트라이얼 이후 리마인드(가입 유도), 신규 가입자 온보딩 안내 |
| 대행 서비스 3종(59,000/79,000/129,000원) | 구현됨(`delivery.py`) | "직접 하기 vs 대행 맡기기" 투트랙 오퍼 — 마케팅 문의 진입 시 업셀 옵션 |

## 4. 마케팅 집행 **전** 필수 확인 체크리스트

이 순서를 건너뛰고 광고 예산부터 쓰면 어디가 새는지 모른 채 돈을 태우게 된다.

1. `GET /admin/growth-funnel?weeks=12`를 관리자 인증으로 직접 호출(현재 페이지 없음, curl/Swagger 사용) — 최근 12주 trial→가입→사업장등록→유료전환 스냅샷 확인
2. `basic_trial_used` 최신 실사용 수 재조회 — 과거 "0명"이 지금도 유효한지
3. Testimonials 실후기 확보 현황(3.5절 참조) — 0건이면 §5-3을 최우선 실행

> **참고**: growth-funnel 엔드포인트 자체의 문서화된 한계 — `trial_scans`는 비로그인이라 개인 단위 코호트 추적 불가(주차별 발생 건수 스냅샷만 가능). 정밀한 개인 추적이 필요하면 `trial_scans`에 `user_id` 컬럼 추가하는 별도 설계가 필요(이번 문서 범위 밖, 후속 과제로만 기재).

## 5. 채널·전술 추천

### 5-1. 무료체험 진입점 최적화 (최우선)
- 랜딩·모든 광고 CTA를 "회원가입"이 아니라 "무료로 내 가게 AI노출 확인하기"(체험)로 통일
- 체험 결과 화면에 4채널 실측 배지를 크게 노출(naeo 대비 유일한 즉시 체감 차별화)
- 체험 직후 카카오 알림톡으로 "가입 시 첫 달 5,950원" 안내 자동 발송(기존 알림톡 인프라 재사용)

### 5-2. 소상공인 커뮤니티 타겟 채널
- 네이버 카페(소상공인·자영업 커뮤니티), 지역 상공회의소, 소상공인시장진흥공단 관련 채널
- 랭킹/배지 같은 바이럴 메커니즘 대신 **"내 가게 하나만 정밀 진단"**이라는 개별 가치 제안 — 지금 AEOlab의 실제 강점과 일치

### 5-3. 베타 후기 확보 (최우선, 비용 거의 없음)
- 실사용 고객 1~3명 인터뷰 → `testimonials.ts`의 `isPlaceholder: false` 전환(코드는 이미 준비돼 있고 텍스트만 교체하면 됨)
- 랭킹으로 사회적 증거를 못 주는 지금, 실후기가 그 공백을 메우는 가장 저비용·고효과 수단

### 5-4. 콘텐츠 마케팅
- "네이버 AI 브리핑에 내 블로그가 왜 안 뜨는지" 같은 실제 진단에서 나온 인사이트를 블로그·SNS 콘텐츠화 — AEOlab 자체가 콘텐츠 마케팅의 소재를 매번 생산함(사용자 데이터 유출 없이 일반화된 패턴만 사용)

## 6. 금지 사항 (반증으로 확인된 리스크)

- **랭킹/배지를 광고 소재로 사용 금지** — §2 참조, 표본 부족 노출 시 역효과
- **"naeo보다 낫다" 식 경쟁사 실명 비교 광고 금지** — 법적 리스크(비교광고 규정). 대신 "국내 유일 4채널 AI 노출 통합 진단" 등 사실 기반 자기 주장으로 대체
- **확보 안 된 후기·수치를 미리 만들어 넣기 금지** — CLAUDE.md 허위수치 금지 원칙과 동일 선상. 실제 후기 확보 전까지 Testimonials 섹션은 계속 숨김 유지

## 7. 실행 우선순위 요약

1. growth-funnel 데이터 확인(§4) — 어디가 새는지 먼저 파악
2. 베타 후기 1~3건 확보(§5-3) — 가장 저비용
3. 무료체험 진입점 카피·CTA 정비(§5-1)
4. 소상공인 커뮤니티 채널 시범 집행(§5-2)
5. (후속 과제, 이 문서 범위 밖) growth-funnel 개인 코호트 추적을 위한 `trial_scans.user_id` 컬럼 추가 검토

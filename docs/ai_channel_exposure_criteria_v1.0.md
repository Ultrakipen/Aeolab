## 1. 네이버 AI 브리핑

### 서비스 정의
통합검색 결과 상단에 AI가 스마트플레이스 데이터를 기반으로 사업장 정보를 자동 요약·추천하는 박스.  
특정 업종·특정 조건 충족 사업장만 노출 대상.

**출시**: 2025-03-24 정식 (2025-06-12 음식점·플레이스 특화 확대)

### 업종 자격 (단일 소스: `score_engine.py:BRIEFING_ACTIVE_CATEGORIES`)

#### ACTIVE — 노출 대상 (5개)
```
restaurant / cafe / bakery / bar / accommodation
```
- 네이버 공식 발표 기준
- **프랜차이즈는 ACTIVE 업종이라도 전면 제외** (네이버 공식 정책)

#### LIKELY — 확대 예정 (실효 6개)
```
beauty / nail / pet / fitness / yoga / pharmacy
```
- 2026 연내 ACTIVE 전환 공식 예고 (네이버 최수연 대표 컨퍼런스콜 2026-02-06, beauty 포함)
- 현재 안내 톤: "AI탭·ChatGPT·Gemini 최적화 우선, AI 브리핑은 확대 예정"
- 점수: ai_briefing_score × 0.5 적용

#### INACTIVE — 비대상
```
medical / legal / education / realestate / interior / auto / shopping / fashion 등 그 외 모든 업종
```
- ai_briefing_score = 0점 고정
- 사용자 안내: 글로벌 AI 채널(ChatGPT·Gemini) 개선 집중 유도

### 핵심 노출 결정 요인 (우선순위 순)

| 순위 | 요인 | 기준값 | AEOlab 측정 |
|------|------|-------|-----------|
| 1 | 스마트플레이스 소개글 (Q&A 포함) | 500자 이상 권장 | ✅ `has_intro` |
| 2 | 리뷰 수·품질·최신성 | 10건 이상 권장, 영수증 리뷰 포함 | ✅ `review_count` |
| 3 | 사진 업로드 (메뉴·매장·카테고리별) | 10장 이상 | ✅ `photo_count` |
| 4 | 소식 최신화 | 14일 이내 소식 1개 이상 | ✅ `has_recent_post` |
| 5 | 예약 연동 | 네이버 예약·캐치테이블 등 | ✅ `has_reservation` |
| 6 | 키워드 커버리지 | 리뷰·소개글 내 핵심 업종 키워드 | ✅ `keyword_gap_score` |
| + | **AI 정보 탭 ON** | 스마트플레이스 내부 토글 | ✅ `ai_info_tab_status` |

> **주의**: "AI 정보 탭"(스마트플레이스 내부 설정 메뉴) ≠ "AI탭"(검색결과 탭) — 혼용 금지

### 점수 반영
```
Track1 naver_exposure_confirmed 가중치: 15점
ACTIVE: in_briefing=True → 15점, False → 0점
ACTIVE + 광고(ad_only=True) → 0점 (유기 점수 미반영)
LIKELY: in_briefing=True → 7.5점
INACTIVE/프랜차이즈: 0점 고정
```

### 사용자 안내 면책 문구
> "AI 브리핑 노출은 네이버 알고리즘 기준이며 보장되지 않습니다. 측정 시점·기기·로그인 상태에 따라 달라질 수 있습니다."

## 2. 네이버 AI탭

### 서비스 정의
통합검색 결과 내 "AI" 탭을 클릭하면 열리는 대화형 AI 검색 서비스.  
사용자 질의에 대해 스마트플레이스·블로그·카페·쇼핑 데이터를 종합해 답변.

**출시**: 2026-04-27 베타 (네이버플러스 구독자 우선) → 2026 상반기 전체 확대 예정

### 업종 자격

**공식 게이팅 없음** — 네이버는 업종 제한 공식 발표 없음.  
단, 현재 베타 기준 에이전트별 우선 지원 업종 확인됨:

| 에이전트 | 업종 | 공식 확인 여부 |
|---------|------|------------|
| 플레이스 에이전트 | 음식점·카페 | ✅ 공식 보도자료·실사용 확인 |
| 쇼핑 에이전트 | 쇼핑·상품 | ✅ 공식 보도자료 확인 |
| 건강 에이전트 (예정) | 병원·의약 | ❌ 미출시 (2026 로드맵) |
| 금융 에이전트 (예정) | 금융·보험 | ❌ 미출시 (2026 로드맵) |

> **코드 반영**: `get_ai_tab_eligibility(category)` → 모든 업종 "beta" 반환 (업종 무관).  
> **사용자 안내 표준**: "음식점·카페·쇼핑 업종 우선 지원 · 업종 확대 예정"  
> "모든 업종 가능" 단정 표현 사용 금지 (근거: 업종 게이팅 발표 없음이 근거이며, 긍정 확인 아님)

### 핵심 노출 결정 요인

> **중요**: 네이버는 AI탭 노출 알고리즘을 공식 미공개 (2026-05 기준). 아래는 공식 보도자료 + 언론 실사용 테스트 기반.

| 요인 | 근거 | 개선 방법 |
|------|------|---------|
| **스마트플레이스 소개글** | 공식: "플레이스 데이터 분석" | Q&A 형식 포함 200자+ |
| **방문자 리뷰 품질·수량** | 공식: "100건 출처 기반 답변 생성" | 경험 위주 상세 리뷰 유도 |
| **블로그 UGC** | 실사용: "블로그 후기 기반 추천" | 외부 블로그 후기 3개 이상 |
| **사진 수·카테고리 다양성** | 공식: "플레이스 데이터" | 10~25장 카테고리별 |
| **예약·결제 연동** | 공식: "검색→예약→결제 원스탑" | 네이버 예약·네이버페이 연동 |
| 운영 정보 최신화 | AI 데이터 소스 신뢰도 | 영업시간·휴무일 정확 유지 |

> **AI 브리핑과 중복 최적화 가능**: 소개글·사진·리뷰는 두 채널 공통 개선 요인.  
> **차별 요인**: AI탭은 예약·결제 연동이 추가 우선순위 신호.

### 점수 반영
```
Track1 ai_tab_readiness 가중치: 5점
in_ai_tab=True (실측) → 보너스 +20 반영
현재 ai_tab_enabled=true (DB) → 스캔 활성화 상태
```

### 사용자 안내 면책 문구
> "AI탭 노출은 네이버 베타 서비스로, 노출 기준이 공식 발표되지 않았습니다. 측정 시점·네이버플러스 구독 여부·기기에 따라 결과가 다를 수 있습니다."

## 3. ChatGPT

### 서비스 정의
OpenAI ChatGPT 앱·웹에서 사용자 질의에 대한 AI 답변.  
AEOlab 스캐너는 **학습 데이터 기반 인식도**를 측정하며, 실사용자가 경험하는 ChatGPT(Bing 검색 연동)와 다를 수 있음.

### 두 개념 명확 구분

| 구분 | AEOlab 스캐너 | 실사용자 ChatGPT |
|------|-------------|---------------|
| 모델 | gpt-4.1-mini (API, web search 미사용) | GPT-5 / 최신 모델 |
| 검색 연동 | 없음 (학습 데이터만) | **Bing 웹 검색 기본 활성화** |
| 측정 내용 | 훈련 데이터 내 인식 빈도 | 최신 웹 검색 결과 기반 답변 |
| 반영 기간 | **수개월~1년** (모델 재학습 주기) | 실시간 (Bing 크롤링 기준) |

> **중요**: GPT 컷오프 2024.06. 2024년 하반기 이후 등록·홍보된 사업장은 스캐너 점수 낮을 수 있음.

### 업종 자격
- **모든 업종 가능** — 제한 없음
- **프랜차이즈 가능** — 브랜드 인지도 의존

### 핵심 노출 결정 요인

#### 스캐너 점수 (학습 데이터 기반, 장기)
| 요인 | 효과 | 측정 |
|------|------|------|
| 자체 웹사이트 + JSON-LD | OAI-SearchBot 크롤링 대상 | ✅ `schema_seo` |
| 언론·뉴스 보도 | 권위 신호, GPT 학습 데이터에 높은 비중 | ✅ `blog_mention_score` |
| 외부 플랫폼 언급 (트립어드바이저 등) | 영어권·글로벌 플랫폼 우선 | 부분 측정 |

#### 실사용자 ChatGPT (Bing 웹 검색 기반, 즉각 효과)
| 요인 | 효과 | 비고 |
|------|------|------|
| **구글 비즈니스 프로필** | Bing도 구글 데이터 참조 → 가장 빠른 경로 | ✅ `schema_seo` |
| 자체 웹사이트 (HTTPS·모바일) | Bing 직접 크롤링 | ✅ |
| 모든 플랫폼 사업장명 통일 (NAP) | AI 정보 신뢰도 향상 | |
| **네이버 블로그** | **Bing 인덱싱 거의 없음 → ChatGPT 직접 효과 없음** | ⚠️ 혼동 금지 |

### 점수 반영
```
Track2 multi_ai_exposure 중 ChatGPT 45점 기여
(언급 횟수 / 총 샘플) × 45 → Gemini 45점과 합산 후 100점 재배분
```

### 면책 문구 (모든 UI 필수)
> "ChatGPT 측정은 AI 학습 데이터(컷오프 2024.06) 기반입니다. 실제 ChatGPT 앱에서의 검색 결과와 다를 수 있으며, 단기 콘텐츠 변경으로 점수가 즉시 변동되지 않습니다."

## 4. Gemini

### 서비스 정의
Google Gemini 앱·웹에서 사용자 질의에 대한 AI 답변.  
실사용자 Gemini는 **Google Search 그라운딩**(실시간 구글 인덱스 참조)이 기본 활성화.  
AEOlab 스캐너는 학습 데이터 기반 측정이지만, 구글 생태계 가중이 높아 ChatGPT보다 **즉각 개선 가능**.

### 두 개념 명확 구분

| 구분 | AEOlab 스캐너 | 실사용자 Gemini |
|------|-------------|--------------|
| 모델 | gemini-2.0-flash-001 (tools 없음) | Gemini 2.5 / 최신 |
| 검색 연동 | 없음 (학습 데이터만) | **Google Search 그라운딩 기본** |
| 반영 기간 | 수개월 (학습 주기) | **수주** (구글 색인 후 즉시) |

### 업종 자격
- **모든 업종 가능** — 제한 없음
- **구글 생태계 연동 여부**가 핵심 변수

### 핵심 노출 결정 요인

| 요인 | 효과 | ChatGPT 대비 | 측정 |
|------|------|------------|------|
| **구글 비즈니스 프로필** | 가장 직접적·빠른 경로 (수주 내 반영) | Gemini 전용 강점 | ✅ `schema_seo` |
| **구글 지도 리뷰** | 감정·키워드 분석 → 신뢰 신호 | Gemini 전용 | ✅ `review_count` |
| **자체 웹사이트 구글 색인** | Search Console 등록 → 그라운딩 즉시 반영 | 공통 (구글 더 빠름) | ✅ |
| **JSON-LD 구조화 데이터** | 구글 Schema.org 파싱 → AI Overview·Gemini 신뢰도 +73% 추정 | 공통 | ✅ `schema_seo` |
| 사진 품질 (구글 Vision AI) | 구글이 Vision AI로 사진 분석 → 카테고리·서비스 자동 인식 | Gemini 전용 | 부분 |
| NAP 정보 일관성 | 플랫폼 간 사업장명·주소·전화 불일치 → 신뢰 하락 | 공통 중요 | |
| **네이버 블로그** | **Gemini 직접 효과 낮음 → 네이버 AI탭·AI브리핑 전용** | ⚠️ 혼동 금지 | |

### 점수 반영
```
Track2 multi_ai_exposure 중 Gemini 45점 기여
(언급 횟수 / 총 샘플) × 45 → ChatGPT 45점과 합산 후 100점 재배분
```

### 면책 문구
> "Gemini 스캐너 측정은 AI 학습 데이터 기반입니다. 실제 Gemini 앱은 Google Search 그라운딩으로 최신 정보를 참조하므로, 구글 비즈니스 프로필 등록·완성 후 수주 내 반영될 수 있습니다."

## 5. Google AI Overview

### 서비스 정의
구글 검색 결과 상단에 AI가 웹 정보를 요약 제시하는 기능.  
한국에서는 2025년 하반기부터 확대 적용 중.

**현재 AEOlab 측정 상태: CAPTCHA 차단으로 직접 측정 불가**  
(iwinv 서버 IP → 구글 CAPTCHA 100%. DataForSEO Screenshot API로 재도입 예정 — 구독자 50명 이후)

### 업종 자격
- **모든 업종 가능** — 제한 없음

### 핵심 노출 결정 요인 (Google 공식 + 2026 연구 기반)

| 요인 | 내용 | 중요도 |
|------|------|-------|
| **JSON-LD 구조화 데이터** | `LocalBusiness`·`Restaurant`·`Product` 스키마 → AI 팩트 추출 신뢰 신호 | 최상 |
| **E-E-A-T** | 경험·전문성·권위·신뢰 — 리뷰·자격·언론 보도·실명 저자 | 최상 |
| **구글 비즈니스 프로필** | 구글 지도 완성도·리뷰·사진 업데이트 | 상 |
| **Core Web Vitals** | 페이지 로딩 속도·CLS·INP (모바일 필수) | 상 |
| **HTTPS + 모바일 최적화** | 기본 기술 요건 | 상 |
| 멀티모달 콘텐츠 | 구조화 데이터 + 이미지 조합 → 인용 가능성 +317% 추정 (Wellows 2026) | 중 |
| NAP 일관성 | 디렉토리 간 정보 불일치 → AI 신뢰 하락 자동 필터 | 중 |

> **Gemini와 개선 경로 공유**: 구글 비즈니스 프로필·JSON-LD·구글 색인은 Gemini와 동시 개선됨.

### 점수 반영
```
Track2 google_presence 가중치: 10점
```

### UI 표시 원칙

1. **채널별 개선 기간 분리 표시** — "네이버: 2~4주" / "ChatGPT·Gemini: 수개월~수주" 병기
2. **면책 문구 의무 적용** — 모든 점수 표시, 트라이얼 결과, PDF 보고서
3. **추정값 배지 사용** — 실측 데이터 없으면 `(추정)` 회색 라벨 + 근거 1줄
4. **"보장" 표현 금지** — "노출됩니다" → "노출 가능성이 높아집니다"
5. **단정 업종 표현 금지** — AI탭 "모든 업종 가능" 사용 금지 (현재 음식점·카페·쇼핑 우선 베타)

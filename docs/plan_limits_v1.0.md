## 플랜별 포지셔닝

| 플랜 | 핵심 타깃 | 차별 기능 | 한계 |
|------|---------|---------|------|
| **무료체험** | AI 진단 첫 경험 | 로그인 없이 즉시 결과 | 1회, 히스토리 없음 |
| **Basic** | 단일 사업장 소상공인 | 주 1회 자동 감시 + AI 콘텐츠 도구 | 경쟁사 3개, 가이드 3회 |
| **창업패키지** | 예비 창업자 | 창업 시장 분석 + Basic 전 기능 | PDF 없음, 사업장 1개 |
| **Pro** | 성장 중인 가게 | 주 3회 스캔 + PDF + 광고대응 + 2사업장 | 창업 분석 없음 |
| **Biz** | 다점포·대행사 | 5사업장 매일 스캔 + 팀 계정 + API | 이메일 영업 전용 |
| **Enterprise** | 프랜차이즈·SI | 무제한 전체 | 영업 협의, 가격 미정 |

## 주의: 창업패키지 vs Pro 교차 구매 방지

창업패키지(12,900원)는 **창업 시장 분석**을 제공하지만 Pro(18,900원)는 제공하지 않는다.
Pro는 대신 **PDF, 광고대응, 주 3회 스캔, 사업장 2개**를 제공한다.

→ 두 플랜은 경쟁이 아닌 상호 보완 관계. 창업 준비 → 창업패키지, 오픈 후 성장 → Pro 전환.

## 1. S급 — 핵심 영업비밀

### 1-1. 듀얼트랙 점수 모델 (score_engine.py)

**가치**: AI 검색 노출을 단일 점수로 환산하는 핵심 알고리즘. 경쟁 서비스 대비 가장 큰 기술 차별화.

```
핵심 내용:
- DUAL_TRACK_RATIO: 9개 업종별 네이버/글로벌 AI 비율
  (restaurant 70/30, legal 20/80, shopping 10/90 등)
- NAVER_TRACK_WEIGHTS v3.0/v3.1/v3.2: Track1 5~6개 항목 가중치
- GLOBAL_TRACK_WEIGHTS: Track2 4개 항목 가중치
- GrowthStage 판정 기준: track1_score 기반 5단계
- ACTIVE/LIKELY/INACTIVE 업종 분류 로직 및 기준
```

**보호 방법**: 코드 비공개, API 응답에 원시 가중치 미노출, 점수만 반환

---

### 1-2. 멀티 AI 샘플링 방법론 (multi_scanner.py)

**가치**: AI 노출을 수치화하는 독자적 통계 방법론. 국내 유일 50/100회 자동 샘플링 측정.

```
핵심 내용:
- Basic 50/50 분할: Gemini 50회 + ChatGPT 50회 병렬
- 점수 재배분 공식: 45+45=90 → 100점 환산
- 쿼리 3변형 균등 분산: divmod(N, 3) 샘플 분배
- Wilson 95% 신뢰구간 적용 (베타 후 도입 예정)
- sample_n 범용화: 10·50·100회 자동 처리
```

**보호 방법**: 알고리즘 상세 미공개, "N회 자동 질의" 표현만 노출

---

### 1-3. keyword_taxonomy 업종별 키워드 그룹 (keyword_taxonomy.py)

**가치**: 25개 업종 × 평균 5~7그룹 × 그룹별 가중치. 수개월 수작업으로 구축.

```
핵심 내용:
- 59개 업종 키워드 화이트리스트 (25개 업종)
- 그룹별 weight 합계 1.0 설계
- ai_tab_context 전용 그룹 (restaurant/cafe/accommodation)
- 롱테일 자연어 질의 5쿼리 생성 로직 (build_ai_scan_queries)
- in_ai_tab / ad_only 전역 플래그
```

**보호 방법**: 코드 비공개, 키워드 목록 미노출

---

### 1-4. AI 콘텐츠 생성 프롬프트 (briefing_engine.py, guide_generator.py)

**가치**: 네이버 C-rank/D.I.A. 알고리즘에 최적화된 소개글·FAQ·소식·블로그 초안 생성 프롬프트.

```
핵심 내용:
- briefing_engine.py: 소개글(_make_intro_content) + FAQ(_make_faq_pair)
  + 소식(_make_list_content_draft) + 리뷰 답변 생성 프롬프트
- D.I.A. 5요소(주제적합도·경험·충실성·독창성·적시성) 강제 삽입 로직
- _find_lsi_cluster(): LSI 연관키워드 자연 배치 알고리즘
- guide_generator.py: Claude Sonnet 가이드 생성 시스템 프롬프트
- FAQ 즉답형(30~60자) 강제 패턴
```

**보호 방법**: 프롬프트 텍스트 클라이언트 미노출, 결과물만 반환

---

### 1-5. 경쟁사 자동 분석 로직 (gap_analyzer.py, competitor_place_crawler.py)

**가치**: 경쟁사 AI 노출 점수를 자동 수집·비교하는 파이프라인. 수동으로는 수시간 소요.

```
핵심 내용:
- _enrich_competitor_excerpts: 경쟁사 키워드 자동 추출
- analyze_review_keyword_distribution: 리뷰 키워드 분포 분석
- keyword_gap cold start: 리뷰→블로그 자동 추출→fallback 30.0
- 경쟁사 점수 배치 계산 파이프라인
```

## 2. A급 — 중요 대외비

### 2-1. 업종별 AI 브리핑 노출 기준 분류 (내부 판단)

```
- ACTIVE 5개 업종 선정 근거 (네이버 공식 + 자체 실측 조합)
- LIKELY 6개 업종 예측 모델
- INACTIVE 업종의 글로벌 AI 최적화 전환 로직
- 프랜차이즈 제외 처리 기준
```

**참고**: 네이버 공식 발표 내용(공개)과 자체 실측 분석(대외비)을 조합한 판단

---

### 2-2. 서비스 원가 구조

```
- Gemini Flash: Basic 50회 기준 월 ~$1.5
- ChatGPT gpt-4o-mini: Basic 50회 기준 월 ~$2
- Claude Sonnet: 가이드 생성 시 ~$3
- 총 BEP 비용: 구독자 20명 기준 월 ~7.5만원
- 마진율: Basic 85%, Pro 78%, Biz 70%
- 요금제별 수익성 분기점
```

---

### 2-3. 스캔 파이프라인 운영 파라미터

```
- Playwright Semaphore(1) 독립 × 2 설계 이유
- 네이버 봇 탐지 우회 타이밍 (wait_for_timeout 값)
- Google CAPTCHA 탐지 로직 (_is_google_captcha)
- 스캔 실패 재시도 전략
- 야간 자동화 스케줄 타이밍 (KST 기준)
```

---

### 2-4. 첫 달 50% 할인 인프라 로직

```
- _is_first_time_subscriber() 서버 재검증 방식
- subscriptions 이력 조회 → 할인 적용 조건
- 클라이언트 amount 조작 차단 로직
- first_month_discount_until = today + 30 처리
```

---

### 2-5. Plan Gate 설계

```
- 플랜별 기능 접근 제어 매트릭스 (PlanGate.tsx)
- scanLimit 플랜별 차등 (월 스캔 횟수)
- 가이드 생성 Claude 호출 월 상한 (MAX_GUIDE_CALLS)
- Pro+ 전용 기능 목록 및 잠금 해제 조건
```

---

### 2-6. 카카오 알림톡 발송 트리거 기준

```
- 점수 변화 알림 발송 임계값 (±N점)
- 경쟁사 변화 감지 알고리즘
- 미작성 콘텐츠 14일 알림 로직 (inactive_post_alert_job)
- AI 탭 트리거 조건 자동 점검 파이프라인
```

## 3. B급 — 일반 대외비

### 3-1. 서버 인프라 상세

```
- iwinv vCPU2/RAM4GB 현재 사양
- 업그레이드 계획 및 임계값 (구독자 N명 이후)
- Nginx 설정 상세 (proxy_buffering off 등)
- PM2 프로세스 구성
- SSH 접근 정보 (당연히 비공개)
```

---

### 3-2. 데이터베이스 스키마 상세

```
- 테이블 간 관계 및 외래키 구조
- RLS(Row Level Security) 정책 상세
- 인덱스 최적화 패턴
- JSONB 컬럼 내부 구조 (blog_analysis_json 등)
```

---

### 3-3. 사용자 데이터 통계

```
- 업종별 평균 점수 분포
- 지역별 경쟁 강도 데이터
- 스캔 결과 집계 통계
- 구독 전환율 퍼널 데이터
```

---

### 3-4. 로드맵 상세

```
- P2 AI탭 스캐너 활성화 트리거 조건
- P3 점수 모델 v3.1 전환 기준 (구독자 N명)
```

## 4. 공개 가능한 것 (마케팅 활용)

```
✅ AI 스캐너 4종 운영 (Gemini·ChatGPT·네이버·Google) 사실
✅ N회 자동 질의 측정 방식 (횟수·원리 일반 수준)
✅ 듀얼트랙 모델 개념 (Track1 네이버 / Track2 글로벌 AI)
✅ 네이버 AI 브리핑 플레이스형 노출 진단 기능
✅ 경쟁사 비교 기능 존재
✅ 업종별 점수 차별화 사실
✅ 네이버 공식 발표 내용 인용 (출처 명시)
✅ 효과 지표 (네이버 공식: 체류 +10.4%, 클릭률 +27.4%)
```
